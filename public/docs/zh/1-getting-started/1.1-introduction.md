# Campus-Auth 简介

Campus-Auth 是面向校园网门户（captive portal）的自动认证工具。检测到离线或被劫持时自动完成登录，支持多网络、验证码与定时任务，解压即用。

## 它帮你做什么

- **宿舍/教学楼断线后自动重连**：不用再手动点登录页，回到在线即恢复
- **多校区、双运营商自动切**：按当前网关 IP 与 WiFi 名称自动匹配对应方案与任务，`auto_switch` 每 60s 检测
- **复杂门户也能跑稳**：二次跳转、iframe 嵌套、运营商下拉、验证码等，通过真浏览器步骤序列覆盖
- **日常事务可定时**：打卡、保活等用 cron 挂到浏览器任务，无需额外脚本

## 核心能力

| 能力 | 要点 |
| --- | --- |
| 断网自愈 | 204 门户检测为主（默认开启），TCP/URL 标题按需；`Captive` 劫持优先于离线 |
| 多网络 | 每条方案独立账号/地址/匹配规则/活跃任务，`default` 兜底不可删 |
| 真浏览器 | Playwright 驱动，`input`/`click`/`select`/`ocr`/`eval` 等 15+ 步骤，`success_condition` 判定 |
| 验证码 | `ocr` 步骤按需，`ddddocr` 约 120MB，设置 → 任务一键安装 |
| 定时任务 | cron 视图，底层仍是浏览器任务 |
| 控制台与托盘 | 本地 `http://127.0.0.1:50721`（端口占用自动 +1，重试 5 次）+ 系统托盘，常驻可用 |

## 技术形态与安全

Rust 控制平面（Tokio + Axum，`src/container.rs` 15 字段拓扑）+ Python Worker 子进程（NDJSON IPC，Playwright / OCR 懒加载，空闲 `300s` 回收）。账号落盘为 `ENC:` 前缀的 AES-256-GCM 密文，内存 `zeroize`；token 在 `config/.auth_token`（`0600`）。
