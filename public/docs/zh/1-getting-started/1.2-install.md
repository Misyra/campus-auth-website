# 安装与运行

## 便携版（推荐）

1. 在 [Releases](https://github.com/Misyra/Campus-Auth-rs/releases) 下载对应包：`Windows x64/arm64` 为 `zip`，`macOS/Linux` 为 `tar.gz`
2. 解压到任意目录（该目录即默认 `base_path`，`--base-path` 可覆盖）
3. Windows 双击 `campus-auth.exe`（GUI 子系统，不弹控制台）；macOS/Linux 执行 `./campus-auth`

首次启动会打开 `http://127.0.0.1:50721` 的初始化向导（使用协议与免责声明），同意后进入仪表盘。

## 端口与已运行实例

- 默认 `127.0.0.1:50721`，占用自动 `+1` 重试 5 次；固定可用 `campus-auth --port 50721` 或 `CAMPUS_AUTH_PORT` / `CAMPUS_AUTH_HOST`
- 双击时若已有实例，会直接在浏览器打开其控制台而非报错；终端可用 `campus-auth --status` / `--stop` / `--force` 查询/停止/抢占
- 轻量模式记哨兵端口 `0`，首个 Web 按需启动后回写真实端口

## 从源码构建

```bash
# 前端先构建，供 rust-embed 嵌入（要求 Node.js）
cd frontend && npm install && npm run build && cd ..

# 编译与运行（要求 Rust 1.85+，仓库 rust-toolchain.toml 固定 1.98）
cargo build
cargo run
# 开发期可跳过前端嵌入：
cargo check --features no-embed
# 运行测试：
cargo test
cargo test test_config_service -- --nocapture
```

## Docker

```bash
docker compose up -d --build
docker compose logs -f
curl http://localhost:50721/api/health
# 仅用 docker CLI：
docker build -t campus-auth .
docker run -d --name campus-auth -p 50721:50721 -v campus-auth-data:/data campus-auth
```

绑 `0.0.0.0` 时控制台仍为 `http://localhost:50721`，数据在命名卷 `campus-auth-data`。进阶见仓库 `docker/README.md`。

## 鉴权

启动生成 `config/.auth_token`（`0600`），前端经 `/api/auth/token` 懒取并在 `X-Auth-Token` / `Bearer` / `?token=` 携带；`GET /api/health` 等少数端点豁免。
