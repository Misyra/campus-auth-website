# 控制台导览

Web 控制台默认 `http://127.0.0.1:50721`（`CAMPUS_AUTH_PORT` / `--port` 可覆盖，占用自动 +1，重试 5 次）。首次走向导，其后在设置里改。

## 主要入口（按控制台真实布局）

- **仪表盘**（`/`）：当前方案、网络状态、日志流与“登录”按钮（`POST /api/login` 执行活跃任务）；Python 未就绪会提示去设置 → 系统修复
- **配置方案**（`/profiles`）：`default` 兜底，多方案列表与 `active_task` 绑定；顶部可开关 `自动切换`，每条可 **编辑/设为活跃/删除**
- **任务管理**（`/tasks`）：浏览器/脚本/定时任务的列表，支持新建/编辑/复制/删除/排序/导入导出与“执行指定任务”（`POST /api/tasks/{id}/execute`）
- **AI 生成任务**（`/ai-task`）与 **自定义脚本**（`/scripts`）：按需
- **定时任务**（`/scheduled`）：cron 调度视图
- **设置**（`/settings`，含子路由）：见下表
- **外观**（`/appearance`）与 **关于**（`/about`，含更新通道与检查）

## 设置的五个子页

| 子页 | 路径 | 管什么 |
| --- | --- | --- |
| 账号 | `/settings/account` | 账号/密码、认证地址 `auth_url`、重定向触发地址 `trigger_url`、运营商 `isp`（含自定义关键字） |
| 网络检测 | `/settings/monitor` | 检测间隔/超时、重试与暂停时段、三种检测的开关与目标（TCP/204/URL 标题）、登录前检测 |
| 系统 | `/settings/system` | Python 环境、启动与运行、自动更新、界面行为、网络/端口/代理、维护操作 |
| 浏览器 | `/settings/browser` | 浏览器选择、基本设置、会话保持、安全与反检测、高级设置 |
| 任务 | `/settings/tasks` | 任务概览、录制器、OCR 依赖与验证码识别 |

> 离开 `/settings` 且有未保存修改时会二次确认，避免丢改动。

## 系统托盘与启动

- Windows：双击已运行实例直接打开控制台；`--status` / `--stop` 在终端可见（附着父控制台）
- macOS：因 `tray-icon` 与 Tokio 主线程冲突，托盘禁用，轻量模式自动回落完整模式
- Linux：依赖 GTK3 / `libayatana-appindicator`，无桌面环境时托盘不启动
- 开机自启：`campus-auth --autostart enable/disable`（计划任务 / LaunchAgent / systemd），或设置 → 系统里开“开机自启动”

## 调试与日志

- 日志与网络状态经 `/ws/logs`、`/ws/status` 实时推送，仪表盘与设置里可看
- 调试走 `POST /api/debug/start` → `step`/`run_all`/`stop`，或前端调试面板单步看 `steps`，`POST /api/debug/capture` 打包截图/MHTML/日志
