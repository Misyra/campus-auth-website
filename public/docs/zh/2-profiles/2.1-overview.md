# 配置方案概览

配置方案（Profile）用于描述某一网络环境下的完整认证配置。每条 Profile 绑定账号、认证地址、匹配规则与活跃任务，Engine 在运行时依据当前网络自动选择最为匹配的方案执行。

## 默认方案

系统安装后默认提供 `default` 方案（兜底项，不可删除）。新部署的设备可直接编辑该方案完成配置；如需支持多校区或多运营商，可另行新建方案。

## Profile 字段

| 字段 | 配置项 | 说明 |
| --- | --- | --- |
| 名称 / 标识 | `name` / `id` | `id` 仅在新建时可指定，`name` 为任意显示名称 |
| 认证地址 | `auth_url` | 登录页的完整 URL；重定向模式下可留空 |
| 触发地址 | `trigger_url` | 仅劫持型网络需填写，非空即进入重定向模式（控制台对应开关“重定向模式（劫持型门户）”） |
| 账号 / 密码 | `username` / `password` | 账号明文提交后自动加密为 `ENC:` 密文落盘；密码输入框显示“已保存，清空可更新” |
| 运营商 | `isp` | 注入模板变量 `{{ISP}}`，参与 `select` / `click_select` 步骤；控制台下拉支持“自定义”关键字输入 |
| 网关 IP | `gateway_ip` | 网络匹配规则之一，详见 [自动匹配](./2.2-match.md) |
| Wi-Fi 名称 | `wifi_ssid` | 网络匹配规则之一 |
| 活跃任务 | `active_task` | 该方案绑定的任务 ID，各网络环境可绑定不同任务，无需为每种环境维护独立的 JSON 副本 |

## 控制台操作

| 操作 | 入口 | 接口 |
| --- | --- | --- |
| 编辑 | 列表中点击 **编辑**，进入三段式编辑器（基本信息 / 网络匹配 / 认证设置） | `PUT /api/profiles/{id}` |
| 设为活跃 | 列表中点击 **设为活跃**，顶栏显示当前方案名称 | `POST /api/profiles/switch` |
| 新建 | 点击 **新建方案**，填写 `id` / `name` / 匹配规则等 | `POST /api/profiles/{id}` |
| 删除 | 列表中点击 **删除**，但 `default` 方案将被拒绝 | `DELETE /api/profiles/{id}` |
| 探测当前网络 | 编辑器内点击 **检测当前网络**，一键将当前网关 IP / SSID 填入对应字段 | `POST /api/profiles/detect` |
| 查询 | 列表与详情页 | `GET /api/profiles` / `GET /api/profiles/active` |

> 活跃任务通过任务管理页的 `POST /api/tasks/active/{id}` 设定（仅浏览器任务可设为活跃），Profile 中的 `active_task` 字段即指向该任务。

## 文件存储

每条 Profile 以独立文件形式存储于 `config/profiles/{id}.json`，密码字段为 `ENC:` 前缀的 AES-256-GCM 密文（详见 [配置文件与目录](../6-reference/6.4-files.md)）。
