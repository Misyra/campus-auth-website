# 三类任务

Campus-Auth 通过“任务”对单次认证或自动化操作进行建模。依据执行方式的差异，任务分为浏览器、脚本、Shell 三类，统一在任务管理页面（`/tasks`）与 设置 → 任务（`/settings/tasks`）中进行管理。

## 类型与存储

| 类型 | `type` | 存储路径 | 适用场景 |
| --- | --- | --- | --- |
| 浏览器 | `browser` | `tasks/browser/*.json` | 需与登录页交互（表单填写、按钮点击、验证码识别、页面跳转及 iframe 处理） |
| 脚本 | `script` | `tasks/scripts/*.json` | 无需浏览器，直接发起 HTTP 请求或调用本地可执行文件 |
| Shell | `shell` | `tasks/scripts/*.json` | 通过单行命令完成认证，如 `curl` 直接登录 |

> 兼容性说明：旧版 JSON 若缺失 `type` 字段，默认按浏览器任务解析；`type` 存在但为未知值时将被校验拒绝（与保存时 `validate_task` 的行为一致，以避免因拼写错误被静默识别为浏览器任务）。

## 超时约束

| 任务类型 | 字段 | 允许范围 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 浏览器 | `timeout` | `1000 … 600000` 毫秒 | `30000` | 超出范围时保存将被拒绝；浏览器会话槽位全局互斥，超时设置过长将占用槽位，影响其他任务执行 |
| 脚本 / Shell | `timeout` | `1 … 3606` 秒 | `60` | 超出范围自动钳制 |

## 共享字段

三类任务均包含 `task_id`（由文件名推导，JSON 中可省略，需符合 `^[a-zA-Z0-9_-]{1,64}$`）、`name`、`description`。脚本与 Shell 任务另有各自的执行字段，详见 [自定义脚本](./3.4-scripts.md)。

## 控制台入口

| 入口 | 路径 | 说明 |
| --- | --- | --- |
| 任务管理 | `/tasks` | 列表中每条任务支持 **执行 / 编辑 / 复制 / 删除**；顶部提供新建空任务、从文件导入、刷新列表等操作 |
| 设置 → 任务 | `/settings/tasks` | 展示任务概览（当前活跃任务名称）、从文件/仓库导入、录制器与 OCR 管理 |
| 定时任务 | `/scheduled` | 以 cron 表达式关联既有浏览器任务的调度视图 |

> 活跃任务仅浏览器任务可设置（`POST /api/tasks/active/{id}`），定时任务的底层亦始终为浏览器任务。

## 接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /api/tasks` / `GET /api/scripts` / `GET /api/shells` | 按类型列出任务 |
| `GET /api/tasks/{id}` / `PUT /api/tasks/{id}` / `DELETE /api/tasks/{id}` | 单条任务的读取 / 更新 / 删除（脚本类 `GET/PUT /api/scripts/{id}` 将拒绝 `ps1` 文件） |
| `POST /api/tasks` / `POST /api/tasks/order` / `POST /api/tasks/import` / `GET /api/tasks/export/{id}` | 创建 / 排序 / 导入 / 导出 |
| `POST /api/tasks/active/{id}` | 设为活跃任务（仅浏览器任务） |
| `POST /api/tasks/{id}/execute` | 执行指定任务（三类通用） |
| `POST /api/scripts/run` | 临时执行脚本（不落盘） |
