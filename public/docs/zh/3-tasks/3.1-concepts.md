# 三类任务

任务文件在运行目录的 `tasks/browser/`（浏览器）与 `tasks/scripts/`（脚本/ Shell）下（`src/tasks/loader.rs`，缺 `type` 时按浏览器任务兼容旧 JSON）。

## 类型与存哪儿

- **浏览器**（`type=browser`）：Playwright 步骤序列，含 `url`/`steps`/`success_condition`，存 `tasks/browser/`
- **脚本**（`type=script`）：`script_path` 或 `content` + `binary_path`/`args`/`work_dir`，存 `tasks/scripts/`
- **Shell**（`type=shell`）：`command` + `shell_path`，存 `tasks/scripts/`

`timeout` 钳制 `1000..600000` 毫秒（浏览器）与 `1..3600` 秒（脚本/ Shell）。

## 控制台入口

- **任务管理**（`/tasks`）：列表中每条可 **执行/编辑/复制/删除**，顶部可建空任务、从文件导入、刷新
- **设置 → 任务**（`/settings/tasks`）：任务概览（当前活跃任务名）、从文件/仓库导入、录制器与 OCR
- 定时任务页（`/scheduled`）是浏览器任务的 cron 视图

## 接口

- 列表与过滤：`GET /api/tasks`、`GET /api/scripts`、`GET /api/shells`
- 单体：`GET/PUT/DELETE /api/tasks/{id}`（脚本单体 `GET/PUT /api/scripts/{id}` 拒绝 `ps1`）
- 创建/排序/导入导出：`POST /api/tasks`、`POST /api/tasks/order`、`POST /api/tasks/import`、`GET /api/tasks/export/{id}`
- 活跃与执行：`POST /api/tasks/active/{id}`（仅浏览器）、`POST /api/tasks/{id}/execute`（三类通用）、临时 `POST /api/scripts/run`
