# 浏览器任务

浏览器任务是 Playwright 驱动的步骤序列，保存以 `src/tasks/models.rs::VALID_STEP_TYPES` 与 `validate_task` 为准，执行以 `python_worker/step_handlers.py` 为准。

## 最小结构

```json
{
  "name": "校园网登录",
  "url": "{{LOGIN_URL}}",
  "timeout": 30000,
  "navigation_wait": 1.0,
  "step_delay": 0.5,
  "reveal_hidden": false,
  "variables": {},
  "success_condition": "login_success",
  "steps": [
    { "id": "fill_username", "type": "input", "selector": "#username", "value": "{{USERNAME}}" },
    { "id": "fill_password", "type": "input", "selector": "#password", "value": "{{PASSWORD}}" },
    { "id": "submit", "type": "click", "selector": "button[type='submit']" },
    { "id": "check_success", "type": "eval", "script": "() => document.body.innerText.includes('登录成功')", "store_as": "login_success" }
  ]
}
```

`url` 非空先自动导航；`timeout 1000..600000ms`，超时会被校验拒绝；未知字段保留为扩展字段。

## 支持的步骤类型

`input` / `click` / `select` / `click_select` / `wait` / `wait_url` / `sleep` / `wait_for_selector` / `eval` / `custom_js` / `evaluate` / `custom` / `goto` / `navigate` / `ocr` / `screenshot` / `assert_text` / `upload_file`

- `eval` / `custom_js` 为推荐，`evaluate` / `custom` 为历史别名
- `wait` 无 `selector` 的固定等待仅兼容旧任务，新任务用 `sleep + duration`

## 步骤要点（控制台里实际可配的）

- **input**：`selector` + `value` + `clear`（默认清空）；`reveal_hidden` 仅特殊门户
- **click**：候选在顶层逗号分割，`:is()` 与属性内逗号不被拆分；失败降级 `dispatch_event("click")`
- **select**：原生 `<select>`，按 `value` / 文本精确 / 唯一子串匹配，`value` 为空跳过
- **click_select**：点 `selector` 展开，`select_delay`（默认 500ms）后在 `option_selector` 范围匹配文本
- **wait / sleep / wait_for_selector**：等 `visible` vs 固定 `duration`；`wait_url` 用 `pattern` 正则等跳转
- **eval / custom_js**：`script`（兼容 `code`）+ `store_as` + `timeout` 真正约束；保存时弹安全确认
- **goto / navigate**：`url`（兼容 `value`/`selector`）+ `wait_until`（`load`/`domcontentloaded`/`networkidle`/`commit`）
- **ocr**：`selector` + 可选 `target_selector` 回填 + `store_as` + `char_range`；未装 OCR 时该步骤失败但非 OCR 任务不受影响
- **assert_text / screenshot / upload_file**：断言、截图与上传
- **frame**：元素步骤可用，`loginFrame` / `url=/portal` / `iframe#login-frame`

## 公共字段与选择器

每个步骤含 `id`（稳定唯一）/ `type` / `description` / `timeout` / `required`（默认 `true`）/ `frame`。选择器优先 `id`/`name`/`data-*`，文本用 `text="登录"`，避免长 class。
