# 浏览器任务

浏览器任务由一组 Playwright 驱动的步骤序列构成，运行于真实浏览器环境中，适用于处理二次跳转、iframe 嵌套、运营商下拉选择、图片验证码等复杂登录页场景。

> 保存时的校验规则以 `src/tasks/models.rs::VALID_STEP_TYPES` 与 `validate_task` 为准，执行逻辑以 `python_worker/step_handlers.py` 为准。本文档与代码实现保持一致。

## 任务结构

```json
{
  "name": "校园网登录",
  "url": "{{LOGIN_URL}}",
  "timeout": 30000,
  "navigation_wait": 1.0,
  "step_delay": 0.5,
  "reveal_hidden": false,
  "variables": {},
  "success_condition": "login_success",
  "steps": [
    { "id": "fill_username", "type": "input", "selector": "#username", "value": "{{USERNAME}}" },
    { "id": "fill_password", "type": "input", "selector": "#password", "value": "{{PASSWORD}}" },
    { "id": "submit", "type": "click", "selector": "button[type='submit']" },
    { "id": "check_success", "type": "eval", "script": "() => document.body.innerText.includes('登录成功')", "store_as": "login_success" }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `url` | 起始导航地址，非空时自动执行导航；劫持型网络建议使用 `{{LOGIN_URL}}` |
| `timeout` | 任务超时时间，`1000…600000` 毫秒，超出范围时保存将被拒绝 |
| `step_delay` | 步骤间延迟，单位为秒，默认 `0.5` |
| `navigation_wait` | 页面加载后的等待时间，单位为秒，默认 `1.0` |
| `reveal_hidden` | 是否揭示隐藏输入框，仅特殊门户需要，保持 `false` 即可 |
| `variables` | 自定义模板变量，详见 [变量与成功判定](./3.3-variables.md) |
| `success_condition` | 成功判定变量名，读取同名 `store_as` 的值进行真值判定 |
| `steps` | 步骤数组，未知字段将保留为扩展字段 |

## 支持的步骤类型

共支持 18 种步骤类型（`VALID_STEP_TYPES`）：

`input` / `click` / `select` / `click_select` / `wait` / `wait_url` / `sleep` / `wait_for_selector` / `eval` / `custom_js` / `evaluate` / `custom` / `goto` / `navigate` / `ocr` / `screenshot` / `assert_text` / `upload_file`

- `eval` / `custom_js` 为推荐写法，`evaluate` / `custom` 为历史别名，执行效果等价。
- `wait` 在无 `selector` 时的固定等待仅为兼容旧任务而保留，新任务请使用 `sleep + duration`。

## 步骤详解

### input — 输入

```json
{ "id": "a", "type": "input", "selector": "#username", "value": "{{USERNAME}}", "clear": true }
```

- `selector` 与 `value` 为必填字段，`clear` 控制是否先清空输入框（默认 `true`）。
- `reveal_hidden` 为任务级开关，仅特殊门户需要启用。

### click — 点击

```json
{ "id": "b", "type": "click", "selector": "button[type='submit']" }
```

- 候选选择器在顶层以逗号分割（`:is()` 与属性内的逗号不参与分割）。
- 执行失败时降级为 `dispatch_event("click")`。

### select — 原生下拉选择

```json
{ "id": "c", "type": "select", "selector": "select[name='isp']", "value": "{{ISP}}" }
```

- 针对原生 `<select>` 元素，按 `value` / 文本精确匹配 / 唯一子串匹配；`value` 为空时跳过执行。
- 存在运营商下拉选项的院校为必填，否则可设置 `required: false`。

### click_select — 自定义下拉选择

```json
{ "id": "d", "type": "click_select", "selector": ".isp-trigger", "option_selector": ".isp-option", "value": "{{ISP}}" }
```

- 点击 `selector` 展开下拉列表，随后在 `option_selector` 范围内匹配文本；`select_delay` 默认 `500ms`。

### wait / sleep / wait_for_selector / wait_url — 等待

| 步骤 | 说明 |
| --- | --- |
| `wait` | 等待元素可见，或在无 `selector` 时作为固定等待（旧任务兼容） |
| `sleep` | 固定等待 `duration` 毫秒 |
| `wait_for_selector` | 等待指定选择器出现 |
| `wait_url` | 通过 `pattern` 正则表达式等待 URL 跳转 |

### eval / custom_js — 脚本执行

```json
{ "id": "e", "type": "eval", "script": "() => document.title", "store_as": "page_title", "timeout": 5000 }
```

- `script`（兼容历史字段 `code`）为必填；`store_as` 指定结果变量名；`timeout` 约束执行时长。
- 保存时将弹出安全确认对话框，确认脚本安全性后方可保存。

### goto / navigate — 页面跳转

```json
{ "id": "f", "type": "goto", "url": "https://auth.example.edu.cn/portal", "wait_until": "networkidle" }
```

- `url`（兼容 `value` / `selector`）与 `wait_until`（`load` / `domcontentloaded` / `networkidle` / `commit`）。
- 适用于多页 SSO 或二次跳转场景。

### ocr — 验证码识别

```json
{ "id": "g", "type": "ocr", "selector": "img#captcha", "target_selector": "input#captcha", "store_as": "captcha_text" }
```

- `selector` 指向验证码图片，`target_selector` 为可选的回填目标输入框，`store_as` 存储识别结果，`char_range` 限制字符范围。
- 未安装 OCR 依赖时该步骤执行失败，但不影响非 `ocr` 任务的正常执行。

### assert_text / screenshot / upload_file — 断言与文件

| 步骤 | 说明 |
| --- | --- |
| `assert_text` | 断言页面文本，用于精确判定 |
| `screenshot` | 截取屏幕并保存至 `path` |
| `upload_file` | 文件上传 |

### frame — iframe 支持

元素类步骤（`input` / `click` / `select` 等）可通过 `frame` 字段指定 iframe：

```json
{ "id": "h", "type": "click", "selector": "#login", "frame": "iframe#login-frame" }
```

支持 `loginFrame` / `url=/portal` / `iframe#login-frame` 等写法。

## 公共字段与选择器

每个步骤均包含 `id`（稳定唯一标识）/ `type` / `description` / `timeout` / `required`（默认 `true`）/ `frame`。

**选择器建议**：优先使用 `id` / `name` / `data-*` 等稳定属性；文本匹配可使用 `text="登录"`；避免使用自动生成的长 class。

## 调试建议

- 动态页面建议将 `navigation_wait` 调整至 `1.5–2.0` 秒，固定等待建议使用 `sleep`。
- 执行失败时，建议先关闭 **后台运行** 进行复现，确认是否存在 iframe 嵌套或选择器失效，再通过调试面板进行单步排查。
