# 自定义脚本

无需浏览器即可完成认证：直接发 HTTP 请求或调本地可执行文件。

## 两类任务（存 `tasks/scripts/`）

- **script**：文件脚本，`script_path`（相对 `tasks/scripts/` 或绝对）或 `content`（内联落临时文件）+ `binary_path` + `args` + `work_dir`
- **shell**：命令字符串 `command` + `shell_path`

`timeout` 钳制 `1..3600` 秒。扩展名支持 `py` / `bat`/`cmd` / `sh` / `exe`/`com`（`src/tasks/executor.rs::build_script_command`）；`ps1` 会被校验拒绝，请用 `bat` 包装或 `shell` 中显式调 `powershell.exe -Command`。

## 口径与执行

- **新建/执行**：控制台 **自定义脚本**（`/scripts`）与任务管理均可，`POST /api/tasks/{id}/execute` 三类通用；脚本支持临时 `POST /api/scripts/run`（不落盘）
- **解释器/ Shell**：`py` 为空时回退到项目内 `python_worker/.venv` 的 Python（触发 `ensure_python_runtime`），其余按系统默认；`shell_path` 为空按 `config.app.shell` / 系统默认（Windows `pwsh→powershell→cmd`，Unix `$SHELL`）
- **变量**：`{{USERNAME}}` / `{{PASSWORD}}` / `{{ISP}}` / `{{LOGIN_URL}}` 同浏览器一致，并注入环境变量
- **平台**：Windows 带 `CREATE_NO_WINDOW` 不弹窗；Unix 超时以进程组 `killpg` 回收；超长输出按 `OUTPUT_TRUNCATE_LEN` 截断；`binary_path`/`script_path` 有元字符与路径穿越校验

## 示例

```bash
# shell 任务：curl 直登
curl -X POST http://127.0.0.1:50721/api/tasks \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: $TOKEN" \
  -d '{"type":"shell","task_id":"curl_login","name":"curl 登录","command":"curl -X POST http://10.0.0.1/login -d username={{USERNAME}} -d password={{PASSWORD}}"}'

# script 内联（内容落临时文件执行）
curl -X POST http://127.0.0.1:50721/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"type":"script","task_id":"http_login","name":"HTTP 登录","content":"import httpx\nr=httpx.post(\"http://10.0.0.1/login\", data={\"username\":\"{{USERNAME}}\",\"password\":\"{{PASSWORD}}\"})\nprint(r.text)","timeout":30}'
```

更多见设置 → 任务的脚本区与接口表。
