# 自定义脚本

无需启动浏览器即可完成认证：直接发起 HTTP 请求或调用本地可执行文件。适用于门户接口较为简单、或需复用既有脚本的场景。

## 任务类型（均存储于 `tasks/scripts/`）

| 类型 | `type` | 必填字段 | 说明 |
| --- | --- | --- | --- |
| 脚本 | `script` | `script_path` 或 `content` 二选一 | 文件脚本：`script_path`（相对于 `tasks/scripts/` 或绝对路径）或 `content`（内联内容，落盘为临时文件后执行）+ `binary_path` + `args` + `work_dir` |
| Shell | `shell` | `command` | 命令字符串 `command` + `shell_path` |

| 字段 | 约束 |
| --- | --- |
| `timeout` | `1 … 3600` 秒，超出范围自动钳制 |
| `content` | 大小上限 `100 KB` |
| `stdout/stderr` | 超长输出按 `500` 字符截断 |
| 扩展名 | 支持 `py` / `bat` / `cmd` / `sh` / `exe` / `com`；`ps1` 将被校验拒绝，请使用 `bat` 包装或在 Shell 任务中显式调用 `powershell.exe -Command` |

## 执行与接口

| 操作 | 入口 | 接口 |
| --- | --- | --- |
| 新建 / 执行 | 控制台 **自定义脚本**（`/scripts`）与任务管理（`/tasks`） | `POST /api/tasks/{id}/execute`（三类任务通用） |
| 临时执行 | 不落盘，适用于一次性验证 | `POST /api/scripts/run` |
| 单条读写 | — | `GET/PUT /api/scripts/{id}`（拒绝 `ps1` 文件） |
| 列表查询 | — | `GET /api/scripts` / `GET /api/shells` |

### 解释器 / Shell 的选择

- `py` 文件：`binary_path` 为空时回退至项目内 `python_worker/.venv` 的 Python 环境（触发 `ensure_python_runtime` 按需初始化）。
- 其余扩展名：`binary_path` 为空时按系统默认方式查找。
- Shell：`shell_path` 为空时按 `config.app.shell` / 系统默认（Windows 为 `pwsh → powershell → cmd`，Unix 为 `$SHELL`）。

### 变量与环境

- `{{USERNAME}}` / `{{PASSWORD}}` / `{{ISP}}` / `{{LOGIN_URL}}` 与浏览器任务一致，同样注入至环境变量。
- 脚本与命令中均可使用模板变量，例如 `curl -d username={{USERNAME}}`。

### 平台差异

- Windows：携带 `CREATE_NO_WINDOW` 标志，不显示弹窗。
- Unix：超时时以进程组 `killpg` 回收，确保子进程一并终止。
- `binary_path` / `script_path` 存在元字符与路径穿越校验。

## 示例

**Shell 任务 — curl 直接登录**：

```bash
curl -X POST http://127.0.0.1:50721/api/tasks \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: $TOKEN" \
  -d '{
    "type": "shell",
    "task_id": "curl_login",
    "name": "curl 登录",
    "command": "curl -X POST http://10.0.0.1/login -d username={{USERNAME}} -d password={{PASSWORD}}"
  }'
```

**Script 内联（内容落盘为临时文件后执行）**：

```bash
curl -X POST http://127.0.0.1:50721/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "type": "script",
    "task_id": "http_login",
    "name": "HTTP 登录",
    "content": "import httpx\nr=httpx.post(\"http://10.0.0.1/login\", data={\"username\":\"{{USERNAME}}\",\"password\":\"{{PASSWORD}}\"})\nprint(r.text)",
    "timeout": 30
  }'
```

更多说明可在 **设置 → 任务** 的脚本区域及接口表中查阅。
