# 断网检测

由 `MonitorService` 的三探针 + 登录前检测决定是否触发自动登录。探针至少启用其一才会自动触发，否则只靠手动登录。

## 在控制台哪里调

**设置 → 网络检测**（`/settings/monitor`）：

- 左侧 **网络状态检测**：`TCP 检测` / `204 门户检测` / `URL 标题检测`
- 右侧 **登录前检测**：`网卡连接检查` / `认证地址可达检查` / `检测不走代理`
- 顶部 **检测与重试**：`检测间隔` / `检测超时` / `最大重试次数` / `重试间隔` / `登录后延迟` / `暂停时段`

## 三探针语义

| 探针 | 开关 | 目标 | 判定 |
| --- | --- | --- | --- |
| TCP | `enable_tcp_check` | `ping_targets`（逗号分隔，缺端口默认 `53`） | 连通即在线 |
| HTTP 204 | `enable_http_check`（默认开） | `test_urls`（`generate_204`） | `204=在线 / 200=劫持`，必须明文 `http` |
| URL 标题 | 开关衍生（`url_check_urls` 非空即开） | 每行 `地址|关键字` | 标题含关键字判在线 |

默认只开 204 是有意的：语义单一、厂商覆盖广、误判率最低；URL 探针为按需标题核对。

## 关键参数与默认值

- `check_interval_seconds 300`、`network_check_timeout 2`、`ping_targets` 默认三项
- `post_login_delay 5`、`max_retries 3`、`retry_interval 5`（指数退避 `5→10→20`）
- `disable_proxy=true` 默认直连，关闭后跟随系统代理（重启生效）
- `暂停时段` 支持跨天（如 `22→6`）

## 与重定向模式配合

劫持型（`trigger_url` 非空）跳过认证地址探测，`Captive` 优先于离线，`{{LOGIN_URL}}` 同步为触发地址。
