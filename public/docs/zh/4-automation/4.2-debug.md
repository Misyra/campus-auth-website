# 录制与调试

## 录制器：不手写 JSON

控制台 **设置 → 任务**（`/settings/tasks`）：

1. 装 Tampermonkey（[tampermonkey.net](https://www.tampermonkey.net/)）
2. 点 **安装录制器脚本**（`/api/tools/task-recorder.user.js`）
3. 打开认证页，点浮动按钮开始，按提示点账号框、密码框、验证码与登录按钮
4. 结束保存为任务，设为活跃并点仪表盘“登录”验证

卡片内含“导出编写指南”与任务手册链接（`/api/docs/...`），实现 `resources/tools/task-recorder.user.js`。

## 验证码 OCR

- 仅 `ocr` 步骤需要；依赖 `ddddocr`（`python_worker` 的 `ocr` extra，约 120MB）
- 同页 **OCR 依赖** 一键安装/卸载，状态实时检测（含大小与重试），未安装时非 OCR 任务不受影响
- **验证码识别** 可选本地图片上传转 base64 调 `ocrApi.recognize` 试识别，验证环境

## 调试

- 前端 **调试面板**（全局挂载）单步看 `steps`，失败可导出反馈包（`POST /api/debug/capture`，截图/MHTML/日志归 `debug/`）
- 接口：`POST /api/debug/start`（先环境就绪检查，缺失自动引导）→ `step` / `run_all` / `stop`；截图经鉴权 WebSocket 内联，不暴露 Worker 绝对路径
- 失败先看仪表盘日志与失败截图（受 `retention_days` 控制），再进调试面板
