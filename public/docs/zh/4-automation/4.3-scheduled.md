# 定时任务

定时任务为浏览器任务的 cron 调度视图（`/scheduled`），底层仍为 `browser` 任务（`src/scheduler`，调度状态持久化于 `tasks/scheduled/`），与离线触发的自动登录相互独立。

## 管理

- 通过控制台 **定时任务** 页面创建调度：选择一个既有浏览器任务，填写 cron 表达式。
- 与 Engine 的登录重试逻辑解耦，专注于打卡、保活等日常自动化场景。

## cron 表达式

格式为 `秒 分 时 日 月 周`，例如：

| 示例 | 说明 |
| --- | --- |
| `0 0 8 * * *` | 每日 8:00 执行 |
| `0 30 7 * * 1-5` | 工作日 7:30 执行 |
| `0 0 */2 * * *` | 每 2 小时执行一次 |

> 建议先通过 **任务管理** 的“执行指定任务”（`POST /api/tasks/{id}/execute`）手动验证任务稳定性，再配置为定时任务。

## 执行时机

- 按 cron 表达式到达设定时间时自动执行关联的浏览器任务。
- 仪表盘“登录”与 `POST /api/tasks/{id}/execute` 为手动触发，仅用于验证，不受定时调度影响。
- 调度状态持久化于 `tasks/scheduled/`，重启后不丢失。
