# 定时任务

定时任务是浏览器任务的 cron 调度视图（`/scheduled`），底层仍为 `browser` 任务（`src/scheduler`，状态在 `tasks/scheduled/`），与离线触发的自动登录互不影响。

## 管理

- 控制台 **定时任务** 页建调度：选已有的浏览器任务，填 cron（如 `0 0 8 * * *` 每天 8 点，`秒 分 时 日 月 周`）
- 与 Engine 的登录重试解耦，专注打卡/保活等日常自动化

## 何时执行

- 按 cron 到点执行关联任务
- 仪表盘“登录”与 `POST /api/tasks/{id}/execute` 为手动触发，用于先验证任务稳再挂定时
