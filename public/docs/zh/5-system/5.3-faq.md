# 常见问题（先看这个）

## 新手必看：为什么不自动登

1. **检测根本没开**：设置 → 网络检测，确认至少一种检测已启用（默认只有 **204 门户检测** 开启，改成全关就不会触发）
2. **地址填错**：直连型填认证地址，劫持型必须开“重定向触发地址”且为 `http`，见快速开始第 2 节
3. **任务没设为活跃**：任务管理里点“设为活跃”，仪表盘的“登录”才会跑它；`POST /api/tasks/{id}/execute` 只是验证用
4. **后台运行开着看不见失败**：设置 → 浏览器 → **后台运行** 关掉再复现一次，看是否在 iframe 里（需要 `frame`）或选择器已失效

## 浏览器相关

**Q：怎么关后台运行先看一次？**

设置 → 浏览器 → **后台运行** 关掉，保存后重跑任务。调稳再开回。控制台没有叫 `headless` 的输入框，只有这个开关（提示为“不显示浏览器窗口。首次配置任务或排查问题时可关闭”）。

**Q：浏览器选哪个？参数怎么加？**

控制台为卡片式选择，默认 `msedge`，可选 `chromium` / `chrome` / `firefox` / `webkit`，支持指向本机已装浏览器；高级设置（需先关“纯净模式”）里 `browser_args` 每行一个，`#` 注释，`--proxy-server` 等敏感参数会被过滤，纯净模式下不生效。

**Q：视口 / 语言 / 时区要改吗？**

多数校园网不用改，默认 `1280×720` / `zh-CN` / `Asia/Shanghai`；遇到按视口做自适应的登录页再调（纯净模式下隐藏）。

**Q：持久化与常驻怎么配？**

设置 → 浏览器 → 会话保持：**记住登录状态**（`persistent_context`，`config/browser-data/{channel}/`，Firefox 不可用）与 **登录完成后保持浏览器进程**（`keep_alive`，关后 `300s` 空闲回收）；右下角可“立即关闭浏览器”。

## OCR / 验证码

**Q：需要装吗？**

只有含 `ocr` 步骤的任务需要；装 `ddddocr` 约 120MB，在 **设置 → 任务** 里看状态一键安装/卸载，未装时非 OCR 任务不受影响。装好后同页“验证码识别”上传本地图片试一次。

## 任务

**Q：`eval` 保存时弹安全警告？**

`eval` / `custom_js` 可执行任意 JS，系统会要求确认，确认安全后保存。

**Q：运营商下拉怎么选？**

原生 `<select>` 用 `select`，自定义下拉用 `click_select`（`selector` 点开 + `option_selector` 范围 + `value={{ISP}}`），没有该下拉就设 `required:false`。

**Q：多校园怎么配？**

默认已有 `default` 方案，多环境再新建一条，各自填 `gateway_ip` / `wifi_ssid` 并开 `auto_switch`，分别绑定 `active_task`，而不是各写一套 JSON 副本；编辑器内“检测当前网络”可一键填入。

## 定时 / 开机 / 长期运行

**Q：定时任务怎么配？**

定时任务页（`/scheduled`）用 cron，如 `0 0 8 * * *` 每天 8 点，先用“执行指定任务”验证稳再挂定时。

**Q：开机自启被拦截？**

设置 → 系统 → 启动与运行的 **开机自启动**，或 `campus-auth --autostart enable`（Windows 计划任务，杀毒可能拦截，把 `campus-auth.exe` 加白名单后重试）。

**Q：长期运行内存涨？**

设置 → 系统 → 维护操作的 **定时自重启**（`auto_restart_hours` 默认 24 小时）与设置 → 浏览器的 **保持浏览器进程** 配合；`keep_alive=false` 默认即用即还（`idle_timeout 300s` 回收）。

## 网络与更新

**Q：Playwright / Chromium 下载失败？**

设置 → 系统 → **Python 环境** 卡片（含进度与重试），或直接等任务/登录时的自动引导；走 `uv` 与多镜像（npmmirror / 清华）尝试，Docker 镜像已预装。

**Q：更新怎么看？**

**关于** 页点“检查更新”，结果回写 `update/last_check.json`，设置 → 系统可见“上次检查时间”与错误提示；通道为正式版/测试版/全通道最新版。

**Q：服务提示已启动但打不开？**

```bash
campus-auth --status
campus-auth --stop
campus-auth --force   # 抢占（含 PID 复用防护）
```

Windows 双击已运行实例会自动打开 `http://127.0.0.1:50721`，轻量模式记哨兵端口 `0`，首个 Web 按需启动后回写真实端口。
