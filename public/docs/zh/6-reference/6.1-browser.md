# 浏览器配置

> 对应 `src/config/schema.rs::BrowserSettings`，控制台路径 **设置 → 浏览器**（`/settings/browser`）。所有字段持久化于 `settings.json → global.browser`。

## 总览

| 分组 | 包含字段 |
| --- | --- |
| 浏览器选择 | `browser_channel` / `browser_custom_path` / `custom_browser_engine` |
| 基本设置 | `timeout` / `navigation_timeout` / `login_timeout` + `locale` / `timezone_id` |
| 后台与资源 | `headless` / `low_resource_mode` 及 5 个开关（详见下表） |
| 会话保持 | `persistent_context` / `keep_alive`（后者位于 `global.worker`，见 [应用与日志](./6.3-system.md)） |
| 高级设置 | `viewport` / `user_agent` / `browser_args` / `extra_headers_json` / `bind_proxy` |

## 浏览器选择

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 浏览器 | `browser_channel` | `msedge` | 卡片式选择：`msedge` / `chromium` / `chrome` / `firefox` / `webkit` |
| 自定义路径 | `browser_custom_path` | 空 | 指向本机已安装浏览器的可执行文件路径 |
| 自定义引擎 | `custom_browser_engine` | `chromium` | 配合自定义路径时的引擎类型：`chromium` / `firefox` / `webkit` |
| 安装 | — | — | `chromium` / `firefox` / `webkit` 支持一键安装（`POST /api/browsers/install`，通过 `npmmirror` 镜像）；已安装 Edge / Chrome 时自动复用，无需下载 |

> **Firefox 限制**：不支持 `persistent_context`（记住登录状态），选择 `firefox` 时该开关自动隐藏。

## 基本设置

| 配置项 | 字段 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- |
| 页面操作超时 | `timeout` | `30` 秒 | `1…120` | 单次页面操作的等待上限 |
| 页面打开超时 | `navigation_timeout` | `15` 秒 | `3…120` | 打开认证页面的最长等待时间 |
| 登录等待上限 | `login_timeout` | `120` 秒 | `10…600` | 手动登录（仪表盘“登录”按钮）的最长等待时间 |
| 浏览器语言 | `locale` | `zh-CN` | — | 发送至网站的语言偏好 |
| 浏览器时区 | `timezone_id` | `Asia/Shanghai` | — | 标准时区名称，留空则跟随系统 |

## 后台运行与资源

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 后台运行 | `headless` | `true` | 启用后不显示浏览器窗口，于后台静默运行，减少对用户的打扰。首次配置任务或排查问题时建议关闭，以便观察实际填入与点击过程 |
| 低资源模式 | `low_resource_mode` | `false` | 不加载图片，降低资源占用；登录页使用图片验证码时请关闭，否则 `ocr` 无法识别 |
| 纯净模式 | `pure_mode` | `false` | 禁用扩展，需关闭后方可显示高级设置（视口 / UA / 附加参数等） |
| 隐身模式 | `stealth_mode` | `false` | 启用反检测脚本，降低被门户识别为自动化操作的概率 |
| 隐身自定义脚本 | `stealth_custom_script` | 空 | 自定义隐身脚本内容，覆盖默认脚本 |
| 禁用 Web 安全 | `disable_web_security` | `false` | 仅调试用途，禁用同源策略 |
| 忽略 HTTPS 错误 | `ignore_https_errors` | `true` | 忽略证书错误，校园网自签证书场景下建议保持启用 |

## 会话保持

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 记住登录状态 | `persistent_context` | `false` | 将 Cookie 等持久化至 `config/browser-data/{channel}/`，不同浏览器数据相互隔离；Firefox 不可用 |
| 保持浏览器进程 | `worker.keep_alive` | `false` | 登录完成后保持浏览器进程常驻，以加快下次登录；关闭后按 `idle_timeout_seconds 300s` 空闲回收。开关位于浏览器设置页，字段位于 `global.worker` |

> 右下角 **立即关闭浏览器** 按钮调用 `POST /api/worker/stop`，仅在调试或更换配置时使用，将中断正在进行的登录流程。

## 高级设置（需先关闭纯净模式）

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 视口 | `viewport_width` / `viewport_height` | `1280×720` | 浏览器视口大小；按视口自适应布局的登录页需调整 |
| User-Agent | `user_agent` | 空（跟随浏览器默认） | 自定义 UA 字符串 |
| 附加请求头 | `extra_headers_json` | 空 | JSON 格式的附加请求头 |
| 附加浏览器参数 | `browser_args` | 空 | 每行一个，`#` 开头为注释；`--proxy-server` 等敏感参数将被过滤，纯净模式下不生效 |
| 绑定代理 | `bind_proxy` | 空 | 浏览器绑定的代理地址 |

> 高级设置在控制台默认隐藏，需先关闭 **纯净模式** 方可显示。

## 配置示例（`settings.json` 片段）

```json
{
  "global": {
    "browser": {
      "headless": true,
      "browser_channel": "msedge",
      "browser_custom_path": "",
      "custom_browser_engine": "chromium",
      "persistent_context": false,
      "pure_mode": false,
      "stealth_mode": false,
      "low_resource_mode": false,
      "disable_web_security": false,
      "viewport_width": 1280,
      "viewport_height": 720,
      "locale": "zh-CN",
      "timezone_id": "Asia/Shanghai",
      "ignore_https_errors": true,
      "timeout": 30,
      "navigation_timeout": 15,
      "login_timeout": 120
    }
  }
}
```
