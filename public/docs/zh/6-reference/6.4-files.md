# 配置文件与目录

> 本页为运行时目录的完整参考，基于 `src/utils/paths.rs` 与 `src/config/mod.rs` 的单一事实来源。

## 运行时目录

默认 `base_path` 为可执行文件所在目录，可通过 `--base-path` 参数或环境变量 `CAMPUS_AUTH_BASE_PATH` 覆盖。

```text
<base_path>/
├── config/                  # 核心配置
│   ├── settings.json        # 全局配置（v6 schema，config_version 驱动迁移）
│   ├── .auth_token          # 鉴权 token（0600，仅本机可读）
│   ├── profiles/
│   │   ├── default.json     # 兜底方案（不可删除）
│   │   └── <id>.json        # 其他 Profile
│   ├── browser-data/
│   │   └── <channel>/       # persistent_context 持久化数据（按浏览器隔离）
│   └── .trash/              # 已删除 Profile 的安全回收站
├── tasks/
│   ├── browser/             # 浏览器任务（type=browser，*.json）
│   ├── scripts/             # 脚本 / Shell 任务（type=script/shell，*.json）
│   └── scheduled/           # 定时调度的状态
├── logs/                    # 按日归档日志（受 retention_days 控制）
├── environment/             # uv / .venv / Playwright 浏览器（按需下载）
├── update/
│   ├── last_check.json      # 上次更新检查结果（last_check_at/has_update/latest_version/error）
│   └── staging/             # 更新产物暂存（自替换前校验 .sha256）
├── debug/                   # 调试打包产物（POST /api/debug/capture）
└── .instance                # 运行中实例的 PID / 端口记录
```

## settings.json

顶层结构（`SettingsData`，v6 schema）：

```json
{
  "config_version": 6,
  "active_profile_id": "default",
  "auto_switch": true,
  "global": {
    "browser": { "...": "见浏览器配置" },
    "monitor": { "...": "见监测与重试" },
    "pause": { "...": "暂停时段" },
    "logging": { "...": "日志" },
    "retry_settings": { "...": "重试策略" },
    "worker": { "...": "Worker" },
    "app": { "...": "应用" },
    "updater": { "...": "自动更新" }
  }
}
```

- `config_version` 驱动自动迁移；损坏时备份为 `settings.corrupt.*`，原子写入经 `.tmp_*.json` 中转。
- 各 `global.*` 字段的详细说明，见 [浏览器配置](./6.1-browser.md)、[监测与重试](./6.2-monitor.md)、[应用与日志](./6.3-system.md)。
- 迁移备份目录前缀 `.backup.v5.`，损坏备份前缀 `settings.corrupt.`，临时文件前缀 `.tmp_`。

## profiles/*.json

每条 Profile 独立存储，结构为 `ProfileData`：

```json
{
  "id": "default",
  "name": "默认网络",
  "username": "20210001",
  "password": "ENC:...",
  "auth_url": "http://10.0.0.1/login",
  "trigger_url": "",
  "isp": "",
  "gateway_ip": "10.0.0.1",
  "wifi_ssid": "Campus-WiFi",
  "active_task": "campus_login"
}
```

- `password` 以 `ENC:` 前缀的 AES-256-GCM 密文落盘，内存中经 `zeroize` 清理；`can_decrypt_password` 失败时脱敏展示。
- 删除时移入 `config/.trash/` 安全目录，而非直接取消链接。

## 任务文件

| 目录 | 类型 | 字段 | 说明 |
| --- | --- | --- | --- |
| `tasks/browser/` | `browser` | `url` / `timeout` / `steps` / `success_condition` 等 | 浏览器任务，详见 [浏览器任务](../3-tasks/3.2-browser.md) |
| `tasks/scripts/` | `script` | `script_path` / `content` / `binary_path` / `args` / `work_dir` | 脚本任务 |
| `tasks/scripts/` | `shell` | `command` / `shell_path` | Shell 任务 |
| `tasks/scheduled/` | — | `cron` + 关联 `task_id` | 定时调度状态 |

> 校验规则：`task_id` 需符合 `^[a-zA-Z0-9_-]{1,64}$`；浏览器任务 `timeout 1000…600000ms`，脚本任务 `timeout 1…3600s`；`content` 上限 `100 KB`。

## 鉴权与端口

| 文件 / 配置 | 说明 |
| --- | --- |
| `config/.auth_token` | 启动时生成，权限 `0600`；前端通过 `GET /api/auth/token` 获取 |
| `config_version` | 当前 `6`（`CURRENT_CONFIG_VERSION`），驱动 schema 迁移 |
| `.instance` | 运行中实例的 PID / 端口记录；`lightweight` 模式下初始记录哨兵端口 `0`，Web 服务按需唤起后回写实际端口 |
| 默认端口 | `127.0.0.1:50721`，端口被占用时自动递增，重试 5 次；Docker 默认 `0.0.0.0:50721` |

## 环境变量与命令行覆盖

| 环境变量 | 命令行 | 说明 |
| --- | --- | --- |
| `CAMPUS_AUTH_PORT` | `--port` | 控制台端口 |
| `CAMPUS_AUTH_HOST` | `--host` | 监听地址 |
| `CAMPUS_AUTH_BASE_PATH` | `--base-path` | 数据根目录 |
| — | `--mode` | `full` / `lightweight` / `login-once` |
| — | `--autostart` | `enable` / `disable` |
| — | `--startup-action` | `monitor` / `login_once` / `none` |
| — | `--no-browser` / `--no-tray` | 不自动打开浏览器 / 不显示系统托盘 |

完整参数可通过 `campus-auth --help` 查看（定义于 `src/launcher.rs::CliArgs`）。

## 清理建议

| 可安全删除（删除后可重建） | 说明 |
| --- | --- |
| `python_worker/.venv` | 约 100 MB+，运行时按需通过 `uv sync` 重建 |
| `logs/` 旧归档 | 超过 `retention_days` 的按日日志 |
| `update/staging/` | 更新产物暂存 |
| `debug/` | 调试打包产物 |

> `settings.json` / `profiles/*.json` / `.auth_token` 包含关键配置与凭据，请勿随意删除。
