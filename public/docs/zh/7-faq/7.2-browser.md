# 浏览器与验证码

## 后台运行

**如何关闭后台运行以便观察执行过程？**

进入 设置 → 浏览器 → **后台运行**，关闭后保存并重新执行任务。调试完成后再重新启用。控制台中无名为 `headless` 的输入框，仅提供此开关（提示为“不显示浏览器窗口。首次配置任务或排查问题时可关闭”）。

## 浏览器选择

**如何选择浏览器？如何附加启动参数？**

控制台提供卡片式选择，默认 `msedge`，可选 `chromium` / `chrome` / `firefox` / `webkit`，支持指向本机已安装的浏览器；高级设置（需先关闭“纯净模式”）中 `browser_args` 按行填写（每行一个，`#` 为注释），`--proxy-server` 等敏感参数将被过滤，纯净模式下不生效。详见 [浏览器配置](../6-reference/6.1-browser.md)。

**视口 / 语言 / 时区是否需要修改？**

多数校园网环境无需修改，默认 `1280×720` / `zh-CN` / `Asia/Shanghai`；仅在登录页按视口自适应时需调整（纯净模式下隐藏）。

**如何配置持久化与常驻？**

进入 设置 → 浏览器 → 会话保持：**记住登录状态**（`persistent_context`，数据位于 `config/browser-data/{channel}/`，Firefox 不可用）与 **登录完成后保持浏览器进程**（`keep_alive`，关闭后 `300s` 空闲回收）；右下角提供“立即关闭浏览器”按钮。

## 验证码

**是否需要安装 OCR 依赖？**

仅含 `ocr` 步骤的任务需要安装；`ddddocr` 约 120 MB，在 **设置 → 任务** 中查看状态并一键安装 / 卸载，未安装时不影响非 OCR 任务的执行。安装完成后，同页“验证码识别”功能可上传本地图片进行测试。

**验证码识别失败或一直重试？**

- 确认 `ocr` 步骤的 `selector` 指向验证码图片元素，而 `target_selector` 指向输入框；两者不可混淆。
- 验证码图片过小或干扰线过重时，可尝试在任务中增加 `wait_for_selector` 等待图片加载完成后再执行 `ocr`。
- 部分门户的验证码需点击刷新，失败重试机制将自动处理，无需手动干预。
