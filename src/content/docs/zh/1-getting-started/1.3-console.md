# 控制台导览

Campus-Auth 的全部配置均在本地 Web 控制台完成，无需手工编辑配置文件。本页面说明各界面的位置与职责，便于后续按图索骥。

## 打开控制台

程序启动后会自动使用默认浏览器打开控制台，默认地址为 `http://127.0.0.1:50721`。若未自动弹出：

- **Windows / macOS / Linux**：未加 `--force` 且开启「自动打开浏览器」时，再次执行启动程序会直接打开**已在运行**实例的控制台（不会重复启动进程）；轻量模式或已关闭自动打开时，重复启动只会提示已有实例在运行。
- 默认监听端口被占用或被 Windows 保留时，回环地址会改由操作系统随机分配可用端口，以实际端口为准；也可执行 `campus-auth --status` 查看当前端口。非回环地址无法自动改绑。

> [!NOTE]
> 控制台与后台 API 共用同一端口。确认服务是否存活，可访问无需鉴权的健康检查接口 `GET /api/health`。

## 初始化向导

首次访问会进入初始化向导，阅读并确认使用协议与免责声明后才会进入仪表盘。该向导仅出现一次，此后直接进入主界面。

## 主导航

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| 仪表盘 | `/` | 查看当前网络状态与实时日志、手动触发一次登录，是日常最常停留的页面 |
| 方案 | `/profiles` | 管理不同网络环境下的账号、登录地址、匹配规则、登录方式与绑定任务 |
| 任务 | `/tasks` | 在不同标签页管理浏览器任务、脚本、定时任务和 AI 生成浏览器任务 |
| 设置 | `/settings` | 网络检测、浏览器、任务与环境、系统、网络与更新、外观等参数（见下表） |
| 外观 | `/settings/appearance` | 主题与界面偏好 |
| 关于 | `/about` | 查看版本、技术栈与系统信息；提供卸载清理 |

> [!NOTE]
> 在 **设置** 页存在未保存修改时离开，会弹出二次确认，避免误操作丢失配置。

## 设置页的分区

设置页是配置的核心，按主题划分为六个分区：

| 分区 | 路径 | 负责内容 |
| --- | --- | --- |
| 检测 | `/settings/monitor` | 三种网络探针的开关与目标、检测间隔与超时、重试策略、暂停时段、登录前检测 |
| 浏览器 | `/settings/browser` | 浏览器选择、是否显示窗口（后台运行）、会话保持、反检测与高级参数 |
| 任务与环境 | `/settings/tasks` | Python 环境初始化、任务概览与导入、录制器、OCR 依赖安装与验证码测试 |
| 系统 | `/settings/system` | 运行模式预设、启动后执行、开机自启、日志设置与界面行为 |
| 网络与更新 | `/settings/network` | 端口与代理、自动更新、手动选择安装包、定时自重启与配置热重载 |
| 外观 | `/settings/appearance` | 主题与界面偏好（旧路径 `/appearance` 会重定向到此） |

![外观设置：背景氛围与主题配色（默认黑白单色）](/screenshots/docs/15-settings-appearance.avif)

各字段的默认值、取值范围与配置文件写法，统一收录在 [settings.json 配置参考](../6-reference/6.1-settings.md)。

## 仪表盘

![仪表盘：统计卡片、快捷操作、登录历史与实时日志](/screenshots/docs/02-dashboard.avif)

- **统计卡片**：开始检测时长、检测次数、登录次数与最后检测时间，快速确认监测是否在正常工作。
- **快捷操作**：**手动登录** 按当前方案的登录方式执行一次（浏览器渠道运行方案绑定的任务，直连渠道发送 HTTP 请求，脚本渠道运行绑定的登录脚本）；**网络测试** 立即执行一轮网络诊断。
- **登录历史**：按时间倒序记录每次登录的结果与耗时，失败原因直接展示在条目中。
- **实时日志**：通过 WebSocket 滚动输出，支持按级别 / 来源筛选与关键字搜索；网络状态变化、登录步骤与失败原因都会即时打印。
- 当浏览器登录所需的 Python 运行环境尚未就绪时，仪表盘顶部会给出明确提示，并引导前往 **设置 → 任务与环境** 修复；直连请求登录完全不需要该环境，脚本登录不启动浏览器（脚本用「项目内解释器」时仍需 Python 环境）。
- 右上角 **启动检测** 用于开始 / 停止网络监测；新安装的「启动后执行」默认不自动开始检测，见 [断网自动重连](../4-automation/4.1-monitor.md)。

## 方案页

- 列出全部方案，内置的 `default` 兜底方案不可删除，新用户直接编辑它即可完成首次配置。
- 当前方案编辑器同时负责账号、登录地址、登录方式与任务绑定；直连任务与登录脚本的正文分别在 **任务 → 直连任务** / **任务 → 脚本** 里配置。
- 页面顶部的 **自动切换** 开关开启后，程序按周期（默认 180 秒）探测当前网关与 Wi-Fi，自动选用最匹配的方案；新配置默认关闭。
- 编辑器内提供 **检测当前网络** 按钮，可一键将当前网关 IP / Wi-Fi 名称填入匹配字段。

机制细节见 [配置方案概览](../2-profiles/2.1-overview.md) 与 [自动匹配网络](../2-profiles/2.2-match.md)。

## 任务页

![任务页：浏览器任务列表、导入入口与 JSON 配置说明](/screenshots/docs/11-tasks.avif)

- 页面分为浏览器任务、直连任务、脚本、定时任务和 AI 生成浏览器任务五个标签页。
- 单条浏览器任务支持 **编辑**、**调试（单步执行）**、**复制为新任务**、**导出 JSON** 与 **删除**；列表顶部提供导入、仓库导入、分享适配与新建入口。
- 浏览器任务由方案编辑器中的 `active_task` 绑定，直连任务与脚本任务分别由 `active_http_task` / `active_script_task` 绑定（任务页仅编辑与调试）；脚本任务也可以单独执行或由定时任务调度。

任务的编写方式见 [三类任务](../3-tasks/3.1-concepts.md) 与 [浏览器任务](../3-tasks/3.3-browser.md)；共享任务的下载方式见 [从仓库下载共享任务](../3-tasks/3.7-repo.md)。

## 调试面板

排查任务时最常用的工具：

- 进入单步调试后，可 **单步执行**、**连续执行**、**随时停止**，逐步查看每个步骤的输出与失败截图。
- **一键取证** 会把浏览器截图、页面快照（MHTML）与日志打包为 `campus-auth-feedback-<时间戳>.zip`，由浏览器**直接下载保存**（不会在程序目录生成）。反馈问题时附上该压缩包可显著提升定位效率。

操作流程见 [调试与取证](../3-tasks/3.6-debug.md)。

## 系统托盘

程序默认常驻系统托盘，提供启动检测 / 停止检测、打开控制台、退出等快捷菜单。各平台存在差异：

| 平台 | 托盘行为 |
| --- | --- |
| Windows | 完整支持；再次双击 exe 会直接打开控制台 |
| macOS | 受系统框架限制暂不支持托盘，轻量模式也会回落到完整模式 |
| Linux | 依赖 GTK3 / appindicator 运行库，无桌面环境时托盘不显示，可追加 `--no-tray` 启动 |
| 通用 | 可在 设置 → 系统 关闭「显示系统托盘」，或启动时追加 `--no-tray` |

开机自启可在 设置 → 系统 中开启，或执行 `campus-auth --autostart enable`（Windows 写入当前用户注册表启动项、macOS 创建 LaunchAgent、Linux 创建 XDG 自启项），详见 [CLI 与运行模式](../5-maintenance/5.2-cli.md)。
