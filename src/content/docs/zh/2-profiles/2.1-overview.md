# 配置方案概览

**方案（Profile）描述「在某个网络环境下如何登录」。** 一条方案绑定了该网络下的账号、认证地址、网络匹配规则、登录方式与待执行的浏览器任务。程序运行时依据当前接入的网络，自动选用最匹配的方案。

可将一条配置方案理解为一张校园网账号卡：宿舍 Wi-Fi、教学楼 Wi-Fi、其他校区、不同运营商，均可各自建立一条配置方案，由程序自动切换。

## 内置方案 `default`

程序首次启动会自动创建 `default` 配置方案，它是系统内置的**兜底方案，不可删除**。

- 仅有一个网络环境时，直接编辑 `default` 即可，无需新建。
- 当其他配置方案均不匹配当前网络时，最终回落到 `default`，确保始终存在可用配置。

## 字段说明

编辑器自上而下分为基本信息、网络匹配（折叠）、账号凭证、认证设置与登录方式几个区块：

![方案编辑器：基本信息与账号凭证](/screenshots/docs/03-profile-editor.avif)

| 字段 | 配置键 | 说明 |
| --- | --- | --- |
| 名称 / 标识 | `name` / `id` | `id` 仅新建时可指定，`name` 为任意显示名 |
| 认证地址 | `auth_url` | 门户登录页的完整 URL。浏览器渠道下**留空即自动跟随重定向**（打开内置触发地址跟随 302，无需任何开关），也可用编辑器内的 **重定向检测** 实测判定；直连渠道留空时 `{auth_url}` 替换为空 |
| 触发地址 | `trigger_url` | 仅劫持型网络更换触发地址时填写（**必须明文 `http`**）；旧版填过的方案继续按重定向运行。入口在 编辑器 → 认证设置 → 重定向高级设置 |
| 账号 / 密码 | `username` / `password` | 提交后自动加密为 `ENC:` 密文落盘；已保存密码时输入框提示「留空保留」，另有独立「清除已保存密码」按钮 |
| 运营商 | `isp` | 注入为模板变量 `{{ISP}}`，供下拉选择步骤使用；支持输入自定义关键字 |
| 网关 IP | `gateway_ip` | 网络匹配规则之一，详见 [自动匹配网络](2.2-match.md) |
| Wi-Fi 名称 | `wifi_ssid` | 网络匹配规则之一 |
| 绑定任务 | `active_task` | 该网络下待执行的浏览器任务 ID；不同网络可绑定不同任务，无需为每种网络复制一份任务文件 |
| 登录方式 | `login_channel` | `browser` 浏览器自动化、`http` 直连请求，或 `script` 自定义脚本；后两者还要分别绑定一个任务（`active_http_task` / `active_script_task`），见 [登录方式怎么选](#登录方式怎么选) |

> [!NOTE]
> 账号密码在本地以 `ENC:` 前缀的 AES-256-GCM 密文保存，内存中及时清零，不会以明文上传至任何服务器。

## 登录方式怎么选

三条渠道决定**这次登录由谁来做**，同一时间只有一条生效：

| 渠道 | 适合谁 | 代价 |
| --- | --- | --- |
| **浏览器自动化** | 想开箱即用的小白用户与简单门户：不用写代码，验证码、动态表单、跳转都能过 | 资源占用最高，需要 Python 环境与浏览器（对内存占用敏感的用户不适合） |
| **直连请求** | 需要轻量运行：一次请求就能登录、表单字段稳定的门户 | 免 Python 与浏览器，最快最省资源；表达不出多步流程与验证码 |
| **自定义脚本** | 自己维护登录逻辑的用户：门户逻辑特殊，要用自己的解释器与库 | 登录逻辑要自己写、自己修；不启动浏览器与 Python Worker（脚本若用「项目内解释器」仍需 Python 环境，只是不装浏览器） |

- 浏览器渠道绑**浏览器任务**（`active_task`），留空时回退内置的 `default` 任务；
- 直连渠道绑**直连任务**（`active_http_task`），字段（请求地址、请求头、判定关键字、凭据变换脚本）在 **任务 → 直连任务** 里编辑，同一门户的多个账号共用一份；
- 脚本渠道绑**脚本任务**（`active_script_task`），登录脚本正文在 **任务 → 脚本** 里编辑。

> [!IMPORTANT]
> 直连与脚本渠道**没有内置的兜底任务**——门户地址与登录逻辑都没法内置。未绑定、或绑定的任务已被删除时，程序会在**保存方案**时就拦下；运行期任务消失则以明确原因终态失败，不会静默回退到浏览器。

## 控制台操作

进入 **方案** 页（`/profiles`）：

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 编辑 | 方案行的 **编辑** | 进入基本信息 / 网络匹配 / 登录方式编辑器 |
| 切换当前方案 | 方案卡片或顶栏下拉 | 手动指定当前使用的方案，顶栏显示其名称 |
| 新建 | **新建方案** | 填写 `id`、名称与匹配规则 |
| 删除 | **删除** | `default` 方案的删除请求会被拒绝 |
| 探测当前网络 | 编辑器内 **检测当前网络** | 一键将当前网关 IP / Wi-Fi 名称填入匹配字段 |

> [!NOTE]
> `active_task` / `active_http_task` / `active_script_task` 都在方案编辑器的「登录方式」块里选择，且只接受对应类型的任务（浏览器 / 直连 / 脚本）。这些绑定是**本机任务 ID**，导出与分享方案时会清空，导入方需要自己重选。

## 存储位置

每条配置方案独立保存为一个文件：`config/profiles/{id}.json`。删除时移入安全回收站 `config/.trash/`，而非直接抹除。完整目录结构见 [目录与文件](../5-maintenance/5.3-files.md)。
