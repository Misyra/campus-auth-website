# 两类任务

Campus-Auth 使用「任务」描述一次自动化操作，当前分为**浏览器任务**和**脚本任务**两类。校园网登录方式由**方案**决定：可以选择浏览器自动化，也可以选择 [直连请求登录](../2-profiles/2.4-http-login.md)；脚本任务不参与校园网登录认证。

## 类型对比

| 类型 | `type` | 保存位置 | 适用场景 |
| --- | --- | --- | --- |
| 浏览器任务 | `browser` | `tasks/browser/*.json` | 操作登录页、填写表单、点击按钮、选择下拉、识别验证码、处理跳转与 iframe |
| 脚本任务 | `script` | `tasks/scripts/*.json` | 不启动浏览器，执行 Python、Shell 包装脚本或本地可执行文件，适合签到、打卡等辅助动作 |

历史 `type=shell` 已移除。读取到旧 Shell 任务时会明确报错并提示改用 `script`，请将命令保存为 `.bat`、`.sh`、`.py` 等脚本后再执行。

## 超时取值范围

| 类型 | 字段 | 允许范围 | 默认值 |
| --- | --- | --- | --- |
| 浏览器任务 | `timeout` | `1000 – 600000` 毫秒 | `30000` |
| 脚本任务 | `timeout` | `1 – 3600` 秒 | `60` |

## 任务与方案的关系

- 浏览器任务是否用于校园网自动登录，由每条方案的 `active_task` 绑定；切换方案时，账号、登录方式和绑定任务一起切换。
- `active_task` 为空或指向不可用任务时，登录流程回退内置 `default` 浏览器任务。
- 脚本任务可以被定时任务调用，但不能作为方案的浏览器登录任务，也不能替代直连请求登录。

## 控制台入口

当前版本将任务相关能力集中在 **任务** 页：

| 标签页 | 用途 |
| --- | --- |
| 浏览器任务 | 新建、编辑、复制、导入/导出和调试浏览器任务 |
| 脚本 | 管理脚本任务并立即执行 |
| 定时任务 | 使用 cron 调度浏览器或脚本任务 |
| AI 生成浏览器任务 | 捕获登录页并生成可编辑的浏览器任务 |

任务页负责编辑；要决定校园网登录使用哪个浏览器任务，请回到 **方案 → 登录方式** 选择。仪表盘的「登录」按钮执行当前方案绑定的任务。

## 相关接口

| 接口 | 作用 |
| --- | --- |
| `GET /api/tasks`、`POST /api/tasks` | 列表与创建任务 |
| `GET/PUT/DELETE /api/tasks/{id}` | 读取、更新、删除任务 |
| `POST /api/tasks/order`、`POST /api/tasks/import`、`GET /api/tasks/export/{id}` | 排序、导入、导出 |
| `POST /api/tasks/{id}/execute` | 立即执行指定任务（浏览器 / 脚本通用） |
| `GET/PUT/DELETE /api/scripts/{id}` | 脚本任务的单条读写 |
| `POST /api/scripts/run` | 临时执行脚本，不落盘 |
