# 三类任务

Campus-Auth 使用「任务」描述一次自动化操作。按执行方式分为**浏览器任务、脚本任务、Shell 任务**三类，统一在 **任务管理** 页（`/tasks`）与 **设置 → 任务**（`/settings/tasks`）中管理。

## 类型对比

| 类型 | `type` | 保存位置 | 适用场景 |
| --- | --- | --- | --- |
| 浏览器任务 | `browser` | `tasks/browser/*.json` | 需与门户登录页交互：填写表单、点击按钮、选择下拉、识别验证码、处理页面跳转与 iframe |
| 脚本任务 | `script` | `tasks/scripts/*.json` | 不启动浏览器，直接执行脚本或本地可执行文件完成认证 |
| Shell 任务 | `shell` | `tasks/scripts/*.json` | 使用一行命令完成认证，例如直接 `curl` 登录接口 |

> [!NOTE]
> 兼容性：缺少 `type` 字段的旧任务文件默认按浏览器任务解析；填写了无法识别的 `type` 时，保存会被校验拒绝，避免拼写错误后被静默当作浏览器任务处理。

> [!IMPORTANT]
> Shell 任务当前**没有控制台新建入口**（自定义脚本 页的「新建脚本」仅创建脚本任务）。创建方式为：手工编写 `tasks/scripts/*.json`（`"type": "shell"` 并填写 `command`），或调用 `POST /api/tasks` 并指定 `type: "shell"`。创建后会正常显示在 自定义脚本 页列表中，可执行、可删除。示例见 [脚本与 Shell 任务](3.5-scripts.md)。

## 超时取值范围

| 类型 | 字段 | 允许范围 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 浏览器任务 | `timeout` | `1000 – 600000` 毫秒 | `30000` | 超出范围时保存被拒绝。浏览器会话槽位全局互斥，超时设置过长会长期占用槽位并影响其他任务 |
| 脚本 / Shell 任务 | `timeout` | `1 – 3600` 秒 | `60` | 超出范围时自动钳制到边界值 |

## 三类任务共有字段

所有任务均包含 `name`、`description`，以及由文件名推导的 `task_id`（JSON 中可省略，需匹配 `^[a-zA-Z0-9_-]{1,64}$`）。脚本任务与 Shell 任务另有各自的执行字段，见 [脚本与 Shell 任务](3.5-scripts.md)。

## 控制台入口

| 入口 | 路径 | 用途 |
| --- | --- | --- |
| 任务管理 | `/tasks` | 逐条执行 / 编辑 / 复制 / 删除；页面顶部可新建、导入、刷新、排序 |
| 设置 → 任务 | `/settings/tasks` | 活跃任务概览、从文件 / 仓库导入、录制器、OCR 管理 |
| 定时任务 | `/scheduled` | 使用 cron 为已有任务挂载定时调度 |

> [!NOTE]
> 仅浏览器任务可被 **设为活跃任务**；定时任务通过 `target_id` 关联目标任务，三类任务均可被定时调度。

## 相关接口

| 接口 | 作用 |
| --- | --- |
| `GET /api/tasks`、`GET /api/scripts`、`GET /api/shells` | 按类型列出任务 |
| `GET/PUT/DELETE /api/tasks/{id}` | 读取 / 更新 / 删除单条任务（脚本类接口拒绝 `ps1` 文件） |
| `POST /api/tasks`、`POST /api/tasks/order`、`POST /api/tasks/import`、`GET /api/tasks/export/{id}` | 创建 / 排序 / 导入 / 导出 |
| `POST /api/tasks/active/{id}` | 设为活跃任务（仅浏览器任务） |
| `POST /api/tasks/{id}/execute` | 立即执行指定任务（三类通用） |
| `POST /api/scripts/run` | 临时执行一段脚本，不落盘 |
