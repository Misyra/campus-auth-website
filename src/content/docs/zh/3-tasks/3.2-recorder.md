# 任务录制器

通过录制器在真实的门户登录页上**按操作顺序点选一遍**，即可生成浏览器任务，无需手工编写 JSON。这是新用户获得首个任务的最快方式。

## 录制流程

录制入口位于 **设置 → 任务**（`/settings/tasks`）：

1. 为浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点击 **安装录制器脚本**（脚本地址 `GET /api/tools/task-recorder.user.js`，源文件位于 `resources/tools/task-recorder.user.js`）。
3. 打开校园网门户登录页，点击页面上的录制浮动按钮，依次点选：账号输入框 → 密码输入框 → 验证码（如有）→ 登录按钮。
4. 结束录制并保存为任务，将其 **设为活跃**，返回仪表盘点击 **登录** 验证。

> [!TIP]
> 录制卡片中还提供「导出编写指南」与任务手册下载，可离线对照查阅。

> [!NOTE]
> 若所在学校已有社区贡献的任务，可先尝试 [从仓库下载共享任务](3.7-repo.md)，省去录制步骤。

## 录制完成后

- **设为活跃任务**：只有活跃任务会在自动重连与定时调度中执行；「执行指定任务」仅用于单次验证。
- **先关闭后台运行再验证一次**：首次验证建议在 设置 → 浏览器 **关闭后台运行（无头模式）**，确认每个步骤均点中目标元素。
- **按需手工微调**：录制结果保存在 `tasks/browser/*.json`。门户较为特殊时可直接编辑，字段说明见 [浏览器任务](3.3-browser.md)，变量规则见 [变量与成功判定](3.4-variables.md)。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 页面上没有录制浮动按钮 | 确认 Tampermonkey 已启用、录制器脚本已安装；刷新登录页后重试 |
| 点击未被记录 | 按「账号框 → 密码框 → 验证码 → 登录按钮」的顺序操作；元素位于 iframe 内时，先点击外层再点击内层 |
| 录制的任务无法跑通 | 使用 [调试与取证](3.6-debug.md) 中的调试面板单步执行定位，常见原因见其中的「常见问题」表 |
