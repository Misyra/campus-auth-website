# 录制器与 AI 生成任务

除[从仓库下载](3.7-repo.md)与手工编写外，程序提供两条「半自动」路径获得浏览器任务：内置的 **AI 生成浏览器任务**（三步向导，开箱即用）与 **任务录制器**（登录页点选元素 → 生成 AI 提示词 → 交给任意大模型）。两者最终都产出可编辑的任务草稿，保存后按文末「生成之后」实测验证。

## 方式一：AI 生成浏览器任务

入口位于 **任务 → AI 生成浏览器任务** 标签页（`/tasks/ai`），按「配置 LLM → 捕获页面 → 生成任务」三步推进：

![AI 生成浏览器任务：三步流程与服务商选择](/screenshots/docs/12-tasks-ai.avif)

**第 1 步 · 配置 LLM 服务**

| 服务商 | 说明 |
| --- | --- |
| OpenCode Zen | **内置快速体验 Key**，开箱即可试用 |
| 智谱 GLM | 推荐使用视觉模型 |
| DeepSeek | 需填写支持图片输入的模型 |
| 其他兼容服务 | OpenAI 兼容的 `chat/completions` 接口 |

模型名必须支持视觉输入；API Key 按服务商分别加密保存在本机（`config/llm.json`），切换服务商自动切换对应 Key。保存后可点击 **测试连接** 验证。

**第 2 步 · 捕获登录页面**：**先退出校园网登录态**（已认证不会跳转到登录页），填写门户地址或任意网址（未登录时访问会自动被跳转），点击 **开始捕获**。

> [!WARNING]
> 页面内容与截图将发送给你配置的 LLM 服务商（内置 Key 对应 OpenCode Zen）。捕获与生成的总时长上限约 10 分钟。

**第 3 步 · 生成并保存任务**：可在「补充说明」里描述门户特性（如「运营商选中国电信」「验证码每 60 秒刷新」），生成后预览 JSON 并保存为任务。

> [!NOTE]
> 该功能仍在开发中。无法生成正确任务时改用方式二；含 `eval` / `custom_js` 的任务保存时同样会弹出安全确认。

## 方式二：任务录制器 + AI 提示词

录制器是一个油猴脚本：在真实门户登录页上**按操作顺序点选元素**，它把所选内容与页面结构整理成一段 **AI 提示词**，交给任意大模型即可得到任务 JSON。相比方式一，它不限制模型服务商，也只上传你点选的元素信息与页面 HTML 摘录。

![任务与环境：录制器入口、任务概览与 OCR 安装](/screenshots/docs/08-settings-tasks.avif)

1. 为浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 在 **设置 → 任务与环境** 点击 **安装录制器脚本**（地址 `GET /api/tools/task-recorder.user.js`，源文件 `resources/tools/task-recorder.user.js`）。
3. 打开门户登录页，点击录制浮动按钮，依次点选：账号输入框 → 密码输入框 → 验证码（如有）→ 登录按钮。
4. 点击 **复制 AI 提示词**，发给任意大模型得到任务 JSON；运行失败时把报错发回，提示词已要求模型提供 `eval` 兜底版本。
5. 在 **任务** 页导入或粘贴生成的 JSON，保存后在 **方案 → 登录方式** 绑定。

同一设置页还提供 **任务编写指南** 与 **任务手册** 下载（`/api/docs/task-writing-guide`、`/api/docs/task-manual`）及 B 站视频教程（03:29 起为录制演示）。

## 生成之后

1. **绑定到方案**：在 **方案 → 登录方式 → 浏览器任务** 中选中它；只有当前方案绑定的任务会用于自动登录。
2. **用调试模式验证**：切到 设置 → 系统 的 **调试模式**（显示浏览器窗口），手动登录一次，确认每步均点中目标元素。
3. **按需微调**：任务保存在 `tasks/browser/*.json`，字段说明见 [浏览器任务](3.3-browser.md)，变量规则见 [变量与成功判定](3.4-variables.md)。
4. **补上成功判定**：生成的任务若未包含 `success_condition`，建议按 [变量与成功判定](3.4-variables.md) 补充 `eval` 判定，否则「步骤执行完」会被当作成功，与实际是否联网无关。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| AI 生成始终失败 | 功能仍在开发中；改用录制器 + 自己的模型，或参考编写指南手工编写 |
| 页面上没有录制浮动按钮 | 确认 Tampermonkey 已启用、录制器脚本已安装；刷新登录页后重试 |
| 点选未被记录 | 按「账号框 → 密码框 → 验证码 → 登录按钮」顺序操作；元素在 iframe 内时先点外层再点内层 |
| 生成的任务跑不通 | 用 [调试与取证](3.6-debug.md) 的调试面板单步定位，把失败步骤反馈给模型修正 |
| 捕获时未跳转到登录页 | 先退出校园网登录态，或直接填写门户登录页地址 |
