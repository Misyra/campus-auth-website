# 浏览器任务

浏览器任务由一串有序步骤组成，由 Playwright 驱动**真实浏览器**执行，适用于二次跳转、iframe 嵌套、运营商下拉、图片验证码等复杂门户登录页。

> [!NOTE]
> 本页字段与代码实现保持一致：步骤类型以 `src/tasks/models.rs` 的 `VALID_STEP_TYPES` 与校验逻辑为准，执行逻辑以 `python_worker/step_handlers.py` 为准。

## 任务整体结构

```json
{
  "name": "校园网登录",
  "url": "{{LOGIN_URL}}",
  "timeout": 30000,
  "navigation_wait": 1.0,
  "step_delay": 0.5,
  "reveal_hidden": false,
  "variables": {},
  "success_condition": "login_success",
  "steps": [
    { "id": "fill_username", "type": "input", "selector": "#username", "value": "{{USERNAME}}" },
    { "id": "fill_password", "type": "input", "selector": "#password", "value": "{{PASSWORD}}" },
    { "id": "submit", "type": "click", "selector": "button[type='submit']" },
    { "id": "check_success", "type": "eval", "script": "() => document.body.innerText.includes('登录成功')", "store_as": "login_success" }
  ]
}
```

顶层字段含义：

| 字段 | 说明 |
| --- | --- |
| `url` | 起始导航地址，非空时先打开该地址；劫持型网络建议使用 `{{LOGIN_URL}}` |
| `timeout` | 任务总超时，`1000 – 600000` 毫秒，超出范围时保存被拒绝 |
| `navigation_wait` | 页面加载后的固定等待秒数，默认 `1.0` |
| `step_delay` | 相邻步骤之间的间隔秒数，默认 `0.5` |
| `reveal_hidden` | 是否强制揭示隐藏输入框，仅特殊门户需要，通常保持 `false` |
| `variables` | 自定义模板变量，见 [变量与成功判定](3.4-variables.md) |
| `success_condition` | 成功判定变量名，读取同名 `store_as` 的结果做真值判断 |
| `steps` | 步骤数组；无法识别的字段会作为扩展字段保留 |

## 步骤类型一览

共 18 种，按用途分组：

| 分组 | 类型 |
| --- | --- |
| 元素操作 | `input`、`click`、`select`、`click_select`、`upload_file` |
| 等待与导航 | `wait`、`wait_url`、`sleep`、`wait_for_selector`、`goto`、`navigate` |
| 脚本与判定 | `eval`、`custom_js`、`evaluate`、`custom`、`assert_text` |
| 其他 | `ocr`、`screenshot` |

> [!NOTE]
> 推荐使用 `eval` / `custom_js`；`evaluate` / `custom` 为历史别名，效果等价。不带 `selector` 的 `wait` 固定等待仅为兼容旧任务保留，新任务请使用 `sleep`。

## 常用步骤详解

### input：填写输入框

```json
{ "id": "a", "type": "input", "selector": "#username", "value": "{{USERNAME}}", "clear": true }
```

`selector` 与 `value` 必填；`clear` 表示填写前是否先清空，默认 `true`。遇到被隐藏的输入框时，可配合任务级 `reveal_hidden` 使用。

### click：点击元素

```json
{ "id": "b", "type": "click", "selector": "button[type='submit']" }
```

多个候选选择器可在顶层用逗号分隔（`:is()` 内部与属性值中的逗号不参与分隔）。普通点击失败时会自动降级为派发 `click` 事件。

### select：原生下拉选择

```json
{ "id": "c", "type": "select", "selector": "select[name='isp']", "value": "{{ISP}}" }
```

面向原生 `<select>` 元素，依次按 `value`、文本精确匹配、唯一子串匹配；`value` 为空时跳过。门户登录页存在运营商下拉时该步骤必填，无运营商选项时可设置 `"required": false`。

### click_select：自定义下拉选择

```json
{ "id": "d", "type": "click_select", "selector": ".isp-trigger", "option_selector": ".isp-option", "value": "{{ISP}}" }
```

先点击 `selector` 展开列表，再在 `option_selector` 范围内按文本匹配选项。展开后的等待时长由 `select_delay` 控制，默认 500 毫秒。

### 等待类步骤

| 步骤 | 作用 |
| --- | --- |
| `wait` | 等待元素可见；不带 `selector` 时为固定等待（旧任务兼容） |
| `sleep` | 固定等待 `duration` 毫秒，默认 1000 |
| `wait_for_selector` | 等待指定选择器出现 |
| `wait_url` | 使用 `pattern` 正则等待 URL 发生跳转 |

### eval / custom_js：执行页面脚本

```json
{ "id": "e", "type": "eval", "script": "() => document.title", "store_as": "page_title", "timeout": 5000 }
```

`script` 必填（历史字段名 `code` 仍兼容）；`store_as` 将返回值存为变量供后续步骤使用；`timeout` 限制执行时长。

> [!WARNING]
> 该步骤可执行任意 JavaScript，保存时会弹出安全确认，确认后才会写入。请仅使用来源可信的任务，详见 [从仓库下载共享任务](3.7-repo.md) 的安全核对一节。

### goto / navigate：页面跳转

```json
{ "id": "f", "type": "goto", "url": "https://auth.example.edu.cn/portal", "wait_until": "networkidle" }
```

`url`（兼容 `value` / `selector`）必填；`wait_until` 可选 `load` / `domcontentloaded` / `networkidle` / `commit`。适用于多页 SSO 与二次跳转场景。

### ocr：验证码识别

```json
{ "id": "g", "type": "ocr", "selector": "img#captcha", "target_selector": "input#captcha", "store_as": "captcha_text" }
```

`selector` 指向验证码图片，`target_selector` 可选、指向待回填的输入框，`store_as` 保存识别结果，`char_range` 可限制字符范围。未安装 OCR 依赖时该步骤失败，但不影响其他不含 OCR 的任务。

> [!NOTE]
> OCR **仅识别一次**（单次调用，超时 90 秒），步骤内不重试；识别失败由上层登录重试整体重跑，详见 [settings.json 配置参考](../6-reference/6.1-settings.md)。

### assert_text / screenshot / upload_file

| 步骤 | 作用 |
| --- | --- |
| `assert_text` | 断言页面文本，用于精确判断 |
| `screenshot` | 截图并保存到 `path` |
| `upload_file` | 上传文件 |

### frame：操作 iframe 内元素

`input` / `click` / `select` 等元素类步骤可使用 `frame` 指定所在的 iframe：

```json
{ "id": "h", "type": "click", "selector": "#login", "frame": "iframe#login-frame" }
```

支持 `loginFrame`、`url=/portal`、`iframe#login-frame` 等写法。元素点击不生效时，请先确认其是否位于 iframe 内。

## 公共字段与选择器建议

每个步骤均支持：`id`（稳定唯一标识）、`type`、`description`、`timeout`、`required`（默认 `true`）、`frame`。

选择器优先级建议：

1. 优先使用稳定的 `id` / `name` / `data-*` 属性；
2. 按文本匹配可使用 `text="登录"`；
3. 避免使用构建工具自动生成的一长串 class，门户改版后极易失效。

## 调试建议

- 动态页面可将 `navigation_wait` 调整至 `1.5–2.0` 秒；需要固定等待时使用 `sleep`。
- 执行不符合预期时，先在 设置 → 浏览器 **关闭后台运行** 复现，确认是否存在 iframe 嵌套或选择器失效，再使用调试面板单步排查，详见 [调试与取证](3.6-debug.md)。
