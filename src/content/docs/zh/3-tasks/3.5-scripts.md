# 脚本与 Shell 任务

当门户登录接口简单、或已有现成脚本时，可**不启动浏览器**直接完成认证：脚本任务直接发起 HTTP 请求或调用本地可执行文件，Shell 任务执行一行命令。二者均保存在 `tasks/scripts/` 目录，在 **自定义脚本** 页（`/scripts`）查看与管理。

> [!IMPORTANT]
> 自定义脚本 页的「新建脚本」**仅能创建脚本任务**，Shell 任务暂无控制台新建入口。创建方式为手工编写 `tasks/scripts/*.json`，或调用本页「相关接口」中的 `POST /api/tasks`。创建后会同样出现在 自定义脚本 页列表中，可执行、可删除。

## 两种类型

| 类型 | `type` | 必填字段 | 说明 |
| --- | --- | --- | --- |
| 脚本任务 | `script` | `script_path` 或 `content` 二选一 | 既可使用文件脚本（`script_path`，相对 `tasks/scripts/` 或绝对路径），也可编写内联 `content`（落盘为临时文件后执行）；可配合 `binary_path`、`args`、`work_dir` |
| Shell 任务 | `shell` | `command` | 一行命令字符串，配合 `shell_path` 指定解释器 |

约束与限制：

| 项目 | 约束 |
| --- | --- |
| 超时 `timeout` | `1 – 3600` 秒，超出范围自动钳制到边界值 |
| 内联 `content` | 上限 100 KB |
| 输出长度 | `stdout` / `stderr` 超过 500 字符的部分截断 |
| 支持扩展名 | `py` / `bat` / `cmd` / `sh` / `exe` / `com`；**不支持 `ps1`**（校验直接拒绝）。请使用 `bat` 包装，或在 Shell 任务中显式调用 `powershell.exe -Command` |

## 解释器选择规则

- **`.py` 文件**：`binary_path` 留空时，自动使用项目内 `python_worker/.venv` 的 Python（必要时触发运行环境初始化）。
- **其他扩展名**：`binary_path` 留空时按系统默认方式查找。
- **Shell 任务**：`shell_path` 留空时，按 `config.app.shell` 或系统默认选择——Windows 依次为 `pwsh` → `powershell` → `cmd`，Unix 为 `$SHELL`。

## 变量与环境变量

`{{USERNAME}}`、`{{PASSWORD}}`、`{{ISP}}`、`{{LOGIN_URL}}` 的用法与浏览器任务一致，既做模板替换也会注入为环境变量。例如命令中可直接书写：

```bash
curl -d username={{USERNAME}} -d password={{PASSWORD}} http://10.0.0.1/login
```

替换规则见 [变量与成功判定](3.4-variables.md)。

## 跨平台行为

- **Windows**：子进程携带 `CREATE_NO_WINDOW` 标志，执行时不弹出控制台窗口。
- **Unix**：超时时按进程组 `killpg` 回收，确保子进程一并终止。
- **路径安全**：`binary_path` / `script_path` 会进行元字符与路径穿越校验，防止命令注入与越界访问。

## 示例

### Shell 任务：一行 curl 登录

```bash
curl -X POST http://127.0.0.1:50721/api/tasks \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: $TOKEN" \
  -d '{
    "type": "shell",
    "task_id": "curl_login",
    "name": "curl 登录",
    "command": "curl -X POST http://10.0.0.1/login -d username={{USERNAME}} -d password={{PASSWORD}}"
  }'
```

### 脚本任务：内联 Python（执行前落为临时文件）

```bash
curl -X POST http://127.0.0.1:50721/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "type": "script",
    "task_id": "http_login",
    "name": "HTTP 登录",
    "content": "import httpx\nr=httpx.post(\"http://10.0.0.1/login\", data={\"username\":\"{{USERNAME}}\",\"password\":\"{{PASSWORD}}\"})\nprint(r.text)",
    "timeout": 30
  }'
```

## 相关接口

| 操作 | 接口 |
| --- | --- |
| 执行任务（三类通用） | `POST /api/tasks/{id}/execute` |
| 临时执行、不落盘 | `POST /api/scripts/run` |
| 单条读写（拒绝 `ps1`） | `GET/PUT /api/scripts/{id}` |
| 列表查询 | `GET /api/scripts`、`GET /api/shells` |
