# 脚本任务

脚本任务让你不经浏览器执行本地动作，例如签到、打卡、调用本地可执行文件或运行一段 Shell / Python 脚本。它保存在 `tasks/scripts/`，由主程序启动本地子进程执行。

脚本任务有两种用途：

- **辅助动作**：在 **任务 → 定时任务** 里用 cron 调度，例如每日签到；
- **登录脚本**：在 **方案 → 登录方式 → 自定义脚本** 里选中它，由它完成校园网登录，凭据经 `CAMPUS_*` 环境变量下发——见 [脚本登录](../2-profiles/2.5-script-login.md)。

## 字段

| 字段 | 含义 |
| --- | --- |
| `content` | 内联脚本内容，执行前写入临时文件，最大 100 KB |
| `script_path` | 相对 `tasks/scripts/` 的脚本路径；绝对路径也必须最终位于该目录内，否则报「script_path 越界」 |
| `binary_path` | 解释器或启动器；为空时按脚本扩展名回退（编辑器里对应「Python (项目内解释器)」这一项） |
| `args` | 命令行参数 |
| `work_dir` | 工作目录；为空时使用脚本所在目录或临时目录 |
| `timeout` | 超时秒数，范围 `1–3600`，默认 60 |

`content` 与 `script_path` 必须二选一，均为空时保存会被拒绝。支持的文件扩展名为 `py`、`bat`、`cmd`、`sh`、`exe`、`com`；不支持 `ps1`、`powershell`、`pwsh`，请使用 `bat` 包装。

当 `binary_path` 为空（编辑器里的默认项「Python (项目内解释器)」）时：`.py` 使用项目内 Python 运行环境，`.bat` / `.cmd` 使用 Windows `cmd.exe`，`.sh` 使用 `sh`，`.exe` / `.com` 直接启动。

## 创建与执行

1. 打开 **任务 → 脚本** 标签页；
2. 新建脚本，填写脚本 ID、名称、执行程序与内容；
3. 保存后点击「运行」立即执行，或在 **定时任务** 中用 cron 调度。

也可使用接口：

```bash
curl -X PUT http://127.0.0.1:50721/api/scripts/checkin \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: $TOKEN" \
  -d '{
    "type": "script",
    "name": "每日签到",
    "content": "from urllib.request import urlopen\nwith urlopen(\"http://example.com/checkin\", timeout=30) as r:\n    print(f\"HTTP {r.status}\")",
    "timeout": 30
  }'
```

临时执行而不落盘：

```bash
curl -X POST http://127.0.0.1:50721/api/scripts/run \
  -H "Content-Type: application/json" \
  -d '{"script": "print(1)"}'
```

## 执行结果与限制

- 进程退出码为 `0` 才判定成功。
- `stdout` 和 `stderr` 合并到 `TaskResult.output`，总长度各自最多 500 字符，随执行响应和任务历史返回。
- 脚本输出**不会**写入 `tracing`、实时日志 WebSocket 或 `GET /api/logs`；排查脚本时请查看任务详情和执行结果。
- 子进程使用最小环境变量，不继承主进程的访问令牌、代理密码等敏感信息。
- Windows 脚本子进程没有显式设置 `CREATE_NO_WINDOW`，启动 `cmd.exe` 或控制台版 Python 时可能短暂出现窗口；需要静默运行时可使用 `pythonw.exe` 或其他无控制台包装方式。
- 超时后 Windows 使用 `taskkill /T` 回收进程树，Unix 使用进程组回收子进程。

脚本任务不做浏览器任务的 `{{USERNAME}}` / `{{PASSWORD}}` 等模板替换，`content` 和 `args` 会按原文执行。

**作为登录脚本**时，凭据由程序注入 `CAMPUS_USERNAME` / `CAMPUS_PASSWORD` / `CAMPUS_ISP` / `CAMPUS_AUTH_URL` 四个环境变量，约定见 [脚本登录](../2-profiles/2.5-script-login.md)。

**作为辅助动作**时没有任何凭据注入，脚本若需要账号密码必须自行设计读取方式；子进程中的 `USERNAME` 是操作系统登录名，不是当前方案账号。
