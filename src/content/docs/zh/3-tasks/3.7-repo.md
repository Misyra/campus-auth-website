# 从仓库下载共享任务

共享任务仓库是由社区维护的公开仓库，收录各高校与常见认证系统的登录任务。**若其中已有所在学校或同型号认证系统的任务，可直接下载使用，无需自行录制或编写**。

> [!IMPORTANT]
> 仓库中的任务由社区成员提交，**未经官方审核验证**。导入前请务必阅读本页「导入前的安全核对」一节。

## 环境前提

下载共享任务前，请确认以下条件已满足：

| 前提 | 说明 |
| --- | --- |
| 程序已启动且控制台可访问 | 导入操作在控制台完成，需能打开 `http://127.0.0.1:50721` |
| 已完成配置方案的凭据填写 | 共享任务本身不含账号密码，运行时通过 `{{USERNAME}}`、`{{PASSWORD}}`、`{{ISP}}`、`{{LOGIN_URL}}` 从当前配置方案注入 |
| 可访问索引地址 | 默认索引托管于 GitHub raw；网络受限时可改用 Gitee 镜像源，或在 设置 → 系统 配置更新代理 |
| 运行环境就绪（仅执行时需要） | 导入动作本身只下载 JSON，不依赖 Python 环境；但执行浏览器任务仍需运行环境初始化完成，见 [启动与安装故障](../7-faq/7.2-startup.md) |

> [!NOTE]
> 仓库下载与程序更新共用同一套代理配置（设置 → 系统 → 自动更新 的「使用代理」与「代理地址」）。该配置与 设置 → 网络监测 的「监测不走代理」相互独立，两者互不影响。

## 索引源

控制台内置三个索引源，可在导入弹窗顶部切换：

| 索引源 | 索引地址 | 适用场景 |
| --- | --- | --- |
| GitHub | `https://raw.githubusercontent.com/Misyra/campus-auth-tasks/master/index.json` | 默认源，任务最全 |
| Gitee | `https://raw.giteeusercontent.com/Misyra/campus-auth-tasks/raw/master/index.gitee.json` | 国内网络访问 GitHub 不稳定时使用，内容与主索引同步 |
| 自定义 | 由使用者自行填写 | 自建仓库或第三方索引 |

仓库地址：<https://github.com/Misyra/campus-auth-tasks>。

## 下载步骤

### 第 1 步：打开导入入口

以下两个入口等价，任选其一：

- **设置 → 任务**（`/settings/tasks`）→ **从仓库导入**
- **任务管理** 页（`/tasks`）→ 顶部 **从仓库导入**

### 第 2 步：选择索引源并加载

1. 在弹窗顶部点击 **GitHub** / **Gitee** / **自定义**，选中后会自动回填对应索引地址。
2. 选择 **自定义** 时，需在输入框中填写完整的远程索引 URL。
3. 点击 **加载索引**，程序会通过本机服务代理拉取索引并展示任务列表。

GitHub 与 Gitee 的 `blob` 页面链接（如 `https://github.com/USER/REPO/blob/master/index.json`）也受支持，程序会自动转换为对应的 raw 地址。

### 第 3 步：检索并查看详情

- 列表支持按任务名称、描述、作者与标签搜索。
- 点击左侧条目，右侧展示该任务的登录页截图、完整描述、作者与标签。
- 作者为项目维护者的任务会标注 **官方任务** 徽标，可信度相对更高。

### 第 4 步：导入并确认免责声明

1. 选中任务后点击 **导入此任务**。
2. 阅读免责声明，确认无误后点击 **确认导入**。
3. 程序下载任务 JSON，并写入任务编辑器**草稿**。

> [!WARNING]
> 导入完成后任务尚未保存，需在编辑器中核对并点击 **保存**，任务才会真正落盘。

## 导入前的安全核对

任务内容是可在门户登录页执行的脚本，**导入前请在编辑器中确认以下四项**：

1. **不含明文凭据。** 账号密码应以 `{{USERNAME}}` / `{{PASSWORD}}` 占位，出现具体账号或密码字面量的任务请勿使用。
2. **导航地址可信。** 检查顶层 `url` 与 `goto` 步骤的地址，应指向学校门户或 `{{LOGIN_URL}}`，而非未知第三方站点。
3. **脚本行为可解释。** 含 `eval` / `custom_js` 步骤时，确认其仅用于填写表单与判定结果，不含外发数据、读取本地文件等操作。
4. **成功判定字段正确。** 程序读取的是 `success_condition`（单数）；部分历史任务使用了 `success_conditions`（复数）写法，需手动改为单数形式，否则成功判定不生效。

> [!NOTE]
> 含 `eval` / `custom_js` 的任务在保存时会弹出安全确认，这是程序的正常设计，并非导入失败。

## 验证步骤

导入并保存后，按以下流程验证任务可用：

1. **关闭后台运行**：进入 设置 → 浏览器，关闭 **后台运行（无头模式）**，使登录过程可见。
2. **设为活跃任务**：在 任务管理 页将该浏览器任务 **设为活跃**，使其绑定到当前配置方案。
3. **手动执行一次**：返回仪表盘点击 **登录**，观察浏览器窗口是否按预期完成填写与提交。
4. **确认登录结果**：网络恢复正常且日志显示成功，即验证通过。
5. **恢复静默执行**：回到 设置 → 浏览器，重新开启 **后台运行**。

若未达预期，按 [调试与取证](3.6-debug.md) 使用调试面板单步执行定位。由于共享任务面向通用门户，通常需要根据本校页面微调选择器，详见 [浏览器任务](3.3-browser.md)。

## 导入后的落盘规则

- 浏览器任务保存为 `tasks/browser/{id}.json`。
- 任务 ID 由索引条目的 `id` 推导：非 `A–Z` / `a–z` / `0–9` / `_` 的字符会被替换为 `_`；以数字开头时自动补 `task_` 前缀。

## 自建索引

若需维护校内私有仓库，索引文件为 JSON 数组，条目结构如下：

```json
[
  {
    "id": "xxx_university",
    "name": "XXX 大学校园网登录",
    "description": "适用于 XXX 大学校园网认证页面",
    "tags": ["XXX 大学", "Dr.COM"],
    "author": "your-name",
    "version": "1.0.0",
    "screenshot": "https://raw.githubusercontent.com/Misyra/campus-auth-tasks/master/snap/demo.png",
    "url": "https://raw.githubusercontent.com/Misyra/campus-auth-tasks/master/tasks/xxx_university.json"
  }
]
```

约束说明：

| 项目 | 约束 |
| --- | --- |
| 索引格式 | 必须为 JSON **数组**；为空或格式不符时提示「索引为空或格式不正确」 |
| 任务格式 | `url` 指向的内容必须为 JSON **对象** |
| 响应体上限 | 8 MiB，超出将中止下载 |
| 请求超时 | 索引与任务 15 秒，任务截图 30 秒 |
| 截图域名 | 仅放行 `raw.githubusercontent.com`、`raw.giteeusercontent.com`、`gitee.com` |

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 点击「加载索引」无响应或长时间无结果 | 多为网络不通。切换为 Gitee 源重试；或在 设置 → 系统 为更新下载配置可用代理 |
| 提示「索引为空或格式不正确」 | 索引内容不是 JSON 数组，或数组为空。核对自定义地址是否为 raw 链接而非 HTML 页面 |
| 任务截图不显示 | 截图地址不在放行域名内，或图片格式不受支持（仅 PNG / JPEG / GIF / WebP / BMP / ICO） |
| 导入后任务列表中找不到 | 导入仅写入编辑器草稿，需在编辑器中点击 **保存** |
| 任务能执行但判定为失败 | 核对 `success_condition` 是否为单数形式，且其引用的 `store_as` 变量确实产生 |
| 想分享本校任务 | 在 任务管理 页导出任务 JSON，按仓库 `README.md` 的说明提交 Issue 或 PR |

## 进阶：相关接口

导入流程由本机服务代理转发，避开浏览器跨域限制。三个接口均需鉴权，其中截图接口例外：

| 接口 | 作用 | 鉴权 |
| --- | --- | --- |
| `GET /api/repo/fetch?url=...` | 代理获取索引（返回 JSON 数组） | 需要 |
| `GET /api/repo/task?url=...` | 代理获取单个任务（返回 JSON 对象） | 需要 |
| `GET /api/repo/image?url=...` | 代理获取任务截图（返回图片字节） | 免鉴权 |
