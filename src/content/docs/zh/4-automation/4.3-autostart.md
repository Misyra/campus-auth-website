# 开机自启与托盘

Campus-Auth 定位为「配置完成后无需干预」的后台工具：开机自动运行、托盘常驻、掉线自动处理。本页面说明这三件事的配置方式。

## 开机自启

以下两种方式任选其一：

- **控制台**：设置 → 系统 → 启动与运行，开启「开机自启动」。
- **命令行**：`campus-auth --autostart enable`（取消使用 `--autostart disable`）。

程序按平台落地：Windows 写入注册表启动项、macOS 创建 LaunchAgent、Linux 创建 XDG 自启项。

### 开机后执行的动作

由「启动后执行」（`startup_action`）控制：

| 值 | 行为 |
| --- | --- |
| `monitor` | 直接进入网络监测，掉线时才登录（默认） |
| `login_once` | 开机先登录一次 |
| `none` | 不执行任何动作 |

> [!NOTE]
> Windows 上若安全软件拦截了自启写入，请将 `campus-auth.exe` 加入白名单后重试，详见 [定时、自启与更新](../7-faq/7.4-misc.md)。

## 托盘常驻

程序默认常驻系统托盘，提供启动 / 停止监测、打开控制台、退出等快捷菜单。各平台存在差异：

| 平台 | 托盘行为 |
| --- | --- |
| Windows | 完整支持；再次双击 exe 会直接打开控制台 |
| macOS | 受系统框架限制暂不支持托盘，轻量模式也会回落到完整模式 |
| Linux | 依赖 GTK3 / appindicator 运行库，无桌面环境时托盘不显示，可追加 `--no-tray` 启动 |
| 通用 | 可在 设置 → 系统 关闭「显示系统托盘」，或启动时追加 `--no-tray` |

若不需要常驻、仅在需要时手动启动，关闭开机自启并追加 `--no-tray` 即可。

## 长期挂机

- **定时自重启**：默认每 24 小时优雅自重启一次（`auto_restart_hours`，设为 `0` 关闭），用于回收浏览器 / Worker 内存，运行时修改无需重启。
- **与启动后执行的配合**：配合 `startup_action=monitor`，重启后自动回到监测状态，实现无人值守。

相关字段（`autostart_enabled` / `startup_action` / `show_tray` / `auto_restart_hours`）的完整说明见 [settings.json 配置参考](../6-reference/6.1-settings.md)。
