# 目录与文件

本页面是运行时目录与落盘文件的完整参考。默认数据根目录（`base_path`）为可执行文件所在目录，可通过 `--base-path` 参数或环境变量 `CAMPUS_AUTH_BASE_PATH` 改至其他位置。

## 完整目录结构

```text
<base_path>/
├── config/                  # 核心配置
│   ├── settings.json        # 全局配置（当前 v6 结构，由 config_version 驱动迁移）
│   ├── .auth_token          # 访问令牌（权限 0600，仅本机可读）
│   ├── .lock                # 实例互斥锁（进程退出由系统自动释放）
│   ├── .instance            # 运行实例的 PID / 端口记录，供 --status 查询
│   ├── .runtime_port        # 服务绑定成功后写入的实际端口
│   ├── profiles/
│   │   ├── default.json     # 内置兜底方案（不可删除）
│   │   └── <id>.json        # 其他配置方案
│   ├── browser-data/
│   │   └── <channel>/       # persistent_context 的持久化数据（按浏览器隔离）
│   └── .trash/              # 已删除配置方案的安全回收站
├── tasks/
│   ├── browser/             # 浏览器任务（type=browser，*.json）
│   ├── scripts/             # 脚本 / Shell 任务（type=script/shell，*.json）
│   └── scheduled/
│       └── history/         # 定时任务执行历史（按调度 ID 分文件）
├── logs/
│   └── login_history/       # 按天归档日志与登录历史（受 retention_days 控制）
├── environment/             # uv / .venv / Playwright 浏览器（按需下载）
├── update/
│   ├── last_check.json      # 上次检查结果
│   ├── pending.json         # 待应用的更新（重启时由 helper 消费）
│   └── staging/             # 更新产物暂存（自替换前校验 .sha256）
├── debug/                   # 一键取证的打包产物
└── python_worker/.venv/     # Python Worker 虚拟环境（按需通过 uv 重建）
```

> [!NOTE]
> 单实例由 `config/.lock` 排他锁保证；`.instance` 仅负责对外提供 PID / 端口查询，两者职责分离。

## settings.json

顶层结构（当前为 v6）：

```json
{
  "config_version": 6,
  "active_profile_id": "default",
  "auto_switch": true,
  "global": {
    "browser": { "...": "见 settings.json 配置参考" },
    "monitor": { "...": "见 settings.json 配置参考" },
    "pause": { "...": "暂停时段" },
    "logging": { "...": "日志" },
    "retry_settings": { "...": "重试策略" },
    "worker": { "...": "Worker" },
    "app": { "...": "应用" },
    "updater": { "...": "自动更新" }
  }
}
```

- 由 `config_version` 驱动自动迁移；写入采用「临时文件中转 + 原子替换」，损坏时先备份为 `settings.corrupt.*`。
- 迁移备份前缀为 `.backup.v5.`，损坏备份前缀为 `settings.corrupt.`，临时文件前缀为 `.tmp_`。
- 各 `global.*` 字段详见 [settings.json 配置参考](../6-reference/6.1-settings.md)。

## profiles/*.json

每条配置方案独立存储，结构为 `ProfileData`：

```json
{
  "id": "default",
  "name": "默认网络",
  "username": "20210001",
  "password": "ENC:...",
  "auth_url": "http://10.0.0.1/login",
  "trigger_url": "",
  "isp": "",
  "gateway_ip": "10.0.0.1",
  "wifi_ssid": "Campus-WiFi",
  "active_task": "campus_login"
}
```

`password` 以 `ENC:` 前缀的 AES-256-GCM 密文落盘，内存中及时清零；解密失败时脱敏展示。删除配置方案时移入 `config/.trash/`，而非直接抹除。

## 任务文件

| 目录 | 类型 | 主要字段 | 说明 |
| --- | --- | --- | --- |
| `tasks/browser/` | `browser` | `url` / `timeout` / `steps` / `success_condition` | 浏览器任务，详见 [浏览器任务](../3-tasks/3.3-browser.md) |
| `tasks/scripts/` | `script` | `script_path` / `content` / `binary_path` / `args` / `work_dir` | 脚本任务 |
| `tasks/scripts/` | `shell` | `command` / `shell_path` | Shell 任务 |
| `tasks/scheduled/` | — | `cron` + `target_id` | 定时调度，详见 [定时任务](../4-automation/4.2-scheduled.md) |
| `tasks/scheduled/history/` | — | 执行历史 | 按调度 ID 分文件记录 |

校验规则：

- `task_id` 需匹配 `^[a-zA-Z0-9_-]{1,64}$`；
- 浏览器任务 `timeout` 为 `1000 – 600000` 毫秒，脚本任务 `timeout` 为 `1 – 3600` 秒；
- 内联 `content` 上限 100 KB；
- 定时任务使用 `target_id`（而非 `task_id`）关联目标，且不持久化 `next_run`（下次触发时间运行时推算）。

## 鉴权与端口

| 文件 / 配置 | 说明 |
| --- | --- |
| `config/.auth_token` | 启动时生成（轻量模式在首次打开控制台时生成），权限 `0600`；前端通过 `GET /api/auth/token` 获取 |
| `config/.lock` | 实例互斥锁，持有它的进程即当前实例 |
| `config_version` | 当前为 `6`，驱动 schema 迁移 |
| `.instance` | 记录 PID / 端口；轻量模式初始为哨兵端口 `0`，控制台唤起后回写真实端口 |
| 默认端口 | `127.0.0.1:50721`，被占用时自动递增、最多重试 5 次；Docker 默认为 `0.0.0.0:50721` |

除 `GET /api/health` 外，以下端点同样免鉴权：`GET /api/system/info`、`GET /api/monitor/status`、`/api/background/*`、`/api/debug/screenshot/*`、`/api/ai/capture/screenshot`、`GET /api/tools/task-recorder.user.js`、`/api/docs/*`；其余接口均需携带令牌。

## 环境变量与命令行覆盖

| 环境变量 | 命令行 | 说明 |
| --- | --- | --- |
| `CAMPUS_AUTH_PORT` | `--port` | 控制台端口 |
| `CAMPUS_AUTH_HOST` | `--host` | 监听地址 |
| `CAMPUS_AUTH_BASE_PATH` | `--base-path` | 数据根目录 |
| — | `--mode` | `full` / `lightweight` / `login-once` |
| — | `--autostart` | `enable` / `disable` |
| — | `--startup-action` | `monitor` / `login_once` / `none` |
| — | `--no-browser` / `--no-tray` | 不自动打开浏览器 / 不显示托盘 |

完整参数可执行 `campus-auth --help` 查看。

## 可安全清理的目录

| 目录 | 说明 |
| --- | --- |
| `python_worker/.venv` | 约 100 MB+，需要时通过 uv 重建 |
| `logs/` 旧归档 | 超过保留天数的按天日志 |
| `update/staging/` | 更新产物暂存 |
| `debug/` | 调试打包产物 |

> [!WARNING]
> `settings.json`、`profiles/*.json`、`.auth_token` 包含关键配置与凭据，请勿随意删除。
