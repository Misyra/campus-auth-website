# 目录与文件

本页面是运行时目录与落盘文件的参考。默认数据根目录（`base_path`）为可执行文件所在目录，可通过 `--base-path` 或环境变量 `CAMPUS_AUTH_BASE_PATH` 改至其他位置。

## 完整目录结构

```text
<base_path>/
├── config/
│   ├── settings.json        # 全局配置（当前 v9 schema）
│   ├── .auth_token          # Web 访问令牌
│   ├── .lock                # 单实例排他锁
│   ├── .instance             # PID / 端口记录
│   ├── .runtime_port         # 实际绑定端口
│   ├── .trash/               # 已删除方案的安全回收站
│   ├── profiles/             # 方案文件
│   │   ├── default.json      # 内置兜底方案
│   │   └── <id>.json
│   ├── browser-data/         # persistent_context 的浏览器数据
│   └── llm.json              # AI 配置，密钥加密保存
├── tasks/
│   ├── browser/              # 浏览器任务（type=browser）
│   ├── scripts/              # 脚本任务（type=script）
│   └── scheduled/            # 定时任务与 history/
├── logs/
│   └── login_history/        # 日志与登录历史
├── environment/              # uv、Python 运行时状态与 OCR 状态
├── python_worker/
│   ├── .venv/                # Python 虚拟环境
│   ├── captures/             # AI 页面捕获结果
│   └── debug/                # 调试快照
└── update/
    ├── last_check.json       # 上次更新检查结果
    ├── pending.json          # 已下载待应用的更新任务
    ├── helper.lock           # 更新助手互斥锁
    └── staging/              # 更新产物暂存
```

Playwright 浏览器位于系统默认缓存目录：Windows 通常是 `%LOCALAPPDATA%\ms-playwright`，macOS 是 `~/Library/Caches/ms-playwright`，Linux 是 `~/.cache/ms-playwright`；Docker 使用镜像内的 `/ms-playwright`。

## settings.json

顶层配置当前为 v9：

```json
{
  "config_version": 9,
  "active_profile_id": "default",
  "auto_switch": false,
  "global": {
    "monitor": { "http_enabled": true, "profile_check_interval": 180 },
    "pause": { "enabled": true, "start_hour": 23, "end_hour": 6 },
    "app": { "startup_action": "none", "port": 50721 },
    "updater": { "channel": "stable" }
  }
}
```

这里只展示关键字段；省略字段会回落到当前版本默认值，完整配置见 [settings.json 配置参考](../6-reference/6.1-settings.md)。低版本配置会自动迁移，升级不会覆盖已保存的 `auto_switch`、`startup_action` 或暂停时段。

## profiles/*.json

每条方案独立存储为 `config/profiles/{id}.json`：

```json
{
  "id": "default",
  "name": "默认网络",
  "username": "20210001",
  "password": "ENC:...",
  "auth_url": "http://10.0.0.1/login",
  "trigger_url": "",
  "isp": "",
  "gateway_ip": "10.0.0.1",
  "wifi_ssid": "Campus-WiFi",
  "active_task": "campus_login",
  "login_channel": "browser",
  "http_method": "post",
  "http_url": "",
  "http_headers": "",
  "http_body": "",
  "http_success_pattern": "",
  "http_failure_pattern": "",
  "http_crypto_script": "",
  "http_ignore_https_errors": null
}
```

`login_channel` 为 `browser` 时使用 `active_task` 指定的浏览器任务；为 `http` 时使用直连请求字段。账号密码落盘为 `ENC:` 前缀的 AES-256-GCM 密文，方案删除时进入安全回收站而非立即抹除。字段详情见 [配置方案概览](../2-profiles/2.1-overview.md) 与 [直连请求登录](../2-profiles/2.4-http-login.md)。

## 任务文件

| 目录 | 类型 | 主要字段 | 说明 |
| --- | --- | --- | --- |
| `tasks/browser/` | `browser` | `url` / `timeout` / `steps` / `success_condition` | Playwright 浏览器任务 |
| `tasks/scripts/` | `script` | `script_path` / `content` / `binary_path` / `args` / `work_dir` | 本地脚本任务 |
| `tasks/scheduled/` | — | `cron` + `target_id` | 定时调度，可关联浏览器或脚本任务 |
| `tasks/scheduled/history/` | — | 执行历史 | 按调度 ID 保存 |

历史 `type=shell` 已移除，旧文件需要改写为 `script` 任务。浏览器任务的 `timeout` 范围为 `1000–600000` 毫秒，脚本任务为 `1–3600` 秒，内联脚本内容上限为 100 KB。

## 环境变量与命令行覆盖

| 环境变量 | 命令行 | 说明 |
| --- | --- | --- |
| `CAMPUS_AUTH_PORT` | `--port` | 控制台端口 |
| `CAMPUS_AUTH_HOST` | `--host` | 监听地址 |
| `CAMPUS_AUTH_BASE_PATH` | `--base-path` | 数据根目录 |
| — | `--mode` | `full` / `lightweight` / `login-once` |
| — | `--autostart` | `enable` / `disable` |
| — | `--startup-action` | `monitor` / `login_once` / `none` |
| — | `--no-browser` / `--no-tray` | 不自动打开浏览器 / 不显示托盘 |

## 访问令牌与端口

`config/.auth_token` 在启动时生成，权限为 `0600`。默认服务仅监听 `127.0.0.1:50721`；回环地址端口冲突时由操作系统随机选择可用端口，实际端口以 `--status`、启动日志或 `.runtime_port` 为准。Docker 默认监听容器内 `0.0.0.0:50721`，请通过反向代理或 VPN 配置远程访问保护，不要裸露到公网。

## 可安全清理

| 目录 | 说明 |
| --- | --- |
| `python_worker/.venv` | Python 环境，需要时自动重建 |
| `python_worker/debug/` | 调试快照与取证包 |
| `logs/` 旧归档 | 超过保留天数的日志 |
| `update/staging/` | 更新暂存产物 |

> [!WARNING]
> `settings.json`、`profiles/*.json`、`.auth_token` 与 `llm.json` 包含关键配置或凭据，请勿随意删除。
