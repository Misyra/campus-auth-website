# 自动更新

## 入口

| 位置 | 说明 |
| --- | --- |
| **设置 → 系统 → 自动更新** | 自动检查更新开关、检查频率、更新通道、上次检查时间及 **立即检查** 操作 |
| **关于**（`/about`）更新卡片 | **检查更新**与 **立即更新**操作 |

## 更新通道

| 通道 | 值 | 说明 |
| --- | --- | --- |
| 正式版 | `stable` | 仅跟随稳定发布 |
| 测试版 | `prerelease` | 仅跟随预发布版本（alpha / beta 等） |
| 全通道最新版 | `all` | 正式版与预发布版本一并按版本号取最高；列表为空时回退至单包口径 |

控制台提供分段按钮：正式版 / 测试版 / 全通道最新版。

## 检查频率与开关

| 配置项 | 字段 | 说明 |
| --- | --- | --- |
| 总开关 | `updater.auto_check_enabled` | 关闭后，后台检查与启动检查均静默处理，仅保留手动“立即检查”；运行时改回无需重启 |
| 启动检查 | `updater.check_on_startup` | 仅 `check_interval_hours == 0` 时独立生效；存在周期性检查时，首轮“立即补查”与启动检查等价 |
| 检查间隔 | `updater.check_interval_hours` | 在 设置 → 系统 中显示为“每次启动 / 每天一次 / 每周一次”（`0 / 24 / 168`），存量非标准值在展示时自动归一 |
| 结果落盘 | `update/last_check.json` | 每次检查无论成功与否均刷新（`last_check_at` / `has_update` / `latest_version` / `error`，UTC RFC3339 格式） |

## 代理配置

| 配置项 | 字段 | 说明 |
| --- | --- | --- |
| 代理开关 | `updater.use_proxy` | 是否使用显式代理下载更新 |
| 代理地址 | `updater.proxy_url` | 如 `http://127.0.0.1:7890`，支持非本机代理 |
| 兼容字段 | `updater.proxy_port` | 旧版“本地代理端口”，仅用于兼容读取；新配置统一写入 `proxy_url` |
| 生效地址 | `resolved_proxy_url()` | `proxy_url` 非空时优先使用；为空时回退至 `proxy_port` 派生的 `http://127.0.0.1:{port}`，两者皆为空则跟随系统代理 |

> 代理配置仅影响更新与任务仓库的下载；网络检测流量由 **设置 → 网络监测 → 监测不走代理** 控制，两者相互独立。

- 更新产物下载至 `update/staging/` 目录，自替换由 `campus-auth-helper` 完成；下载前执行 `.sha256` 校验。

## 故障排查

| 场景 | 建议 |
| --- | --- |
| 代理环境下载失败 | 在 设置 → 系统 → 网络、端口与代理 中填写 `http://127.0.0.1:7890`（支持非本机代理），留空则跟随系统代理 |
| 查看检查结果 | 关于页面与 设置 → 系统 中的“上次检查时间”及错误提示，均来自 `last_check.json` 的 `error` / `latest_version` 字段 |
| 切换更新通道 | 在 设置 → 系统 或关于页面切换通道后，点击“立即检查” |
