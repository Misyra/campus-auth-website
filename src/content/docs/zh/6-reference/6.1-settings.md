# settings.json 配置参考

本页面汇总全部全局配置字段，对应四个设置分区，持久化在 `settings.json → global.*`：

| 分区 | 设置页位置 | 字段前缀 |
| --- | --- | --- |
| 浏览器 | 设置 → 浏览器（`/settings/browser`） | `global.browser`、`global.worker` |
| 网络监测与重试 | 设置 → 网络监测（`/settings/monitor`） | `global.monitor`、`global.pause`、`global.retry_settings` |
| 应用、Worker 与日志 | 设置 → 系统（`/settings/system`） | `global.app`、`global.worker`、`global.logging` |
| 自动更新 | 设置 → 系统 → 更新 | `global.updater` |

初次使用只需关注「后台运行」与「浏览器选择」，其余保持默认值即可。目录与文件的整体结构见 [目录与文件](../5-maintenance/5.3-files.md)。

## 浏览器

对应字段前缀：`global.browser`。

### 浏览器选择

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 浏览器 | `browser_channel` | `msedge` | 卡片式选择：`msedge` / `chromium` / `chrome` / `firefox` / `webkit` |
| 自定义路径 | `browser_custom_path` | 空 | 指向本机已安装浏览器的可执行文件 |
| 自定义引擎 | `custom_browser_engine` | `chromium` | 配合自定义路径使用：`chromium` / `firefox` / `webkit` |
| 一键安装 | — | — | `chromium` / `firefox` / `webkit` 可一键安装（走 npmmirror 镜像）；本机已安装 Edge / Chrome 时直接复用，无需下载 |

> [!NOTE]
> Firefox 不支持「记住登录状态」（`persistent_context`），选中 Firefox 时该开关自动隐藏。

### 基本设置

| 配置项 | 字段 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- | --- |
| 页面操作超时 | `timeout` | 30 秒 | 1–120 | 单次页面操作的等待上限 |
| 页面打开超时 | `navigation_timeout` | 15 秒 | 3–120 | 打开门户登录页的最长等待 |
| 登录等待上限 | `login_timeout` | 120 秒 | 10–600 | 手动点击「登录」后的最长等待 |
| 浏览器语言 | `locale` | `zh-CN` | — | 发送给网站的语言偏好 |
| 浏览器时区 | `timezone_id` | `Asia/Shanghai` | — | 标准时区名，留空时跟随系统 |

### 后台运行与资源

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 后台运行（无头） | `headless` | `true` | 开启后不显示浏览器窗口、后台静默执行。**首次配置任务或排查问题时建议关闭**，以便观察填写与点击过程 |
| 低资源模式 | `low_resource_mode` | `false` | 不加载图片以节省资源；门户使用图片验证码时必须关闭，否则 OCR 无图可识别 |
| 纯净模式 | `pure_mode` | `false` | 禁用扩展；需关闭后才显示高级设置 |
| 隐身模式 | `stealth_mode` | `false` | 注入反检测脚本，降低被门户识别为自动化的概率 |
| 隐身自定义脚本 | `stealth_custom_script` | 空 | 自定义反检测脚本，覆盖默认脚本 |
| 禁用 Web 安全 | `disable_web_security` | `false` | 仅调试用，关闭同源策略 |
| 忽略 HTTPS 错误 | `ignore_https_errors` | `true` | 忽略证书错误，校园网自签证书场景建议保持开启 |

### 会话保持

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 记住登录状态 | `persistent_context` | `false` | 将 Cookie 等持久化到 `config/browser-data/{channel}/`，不同浏览器相互隔离；Firefox 不可用 |
| 保持浏览器进程 | `worker.keep_alive` | `false` | 登录后让浏览器进程常驻以加快下次登录；关闭时空闲 300 秒（`idle_timeout_seconds`）后自动回收。开关位于浏览器设置页，字段归属 `global.worker` |

> [!NOTE]
> 页面右下角「立即关闭浏览器」会中断正在进行的登录，仅在调试或更换配置时使用。

### 高级设置

需先关闭纯净模式后才会显示。

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 视口 | `viewport_width` / `viewport_height` | 1280×720 | 浏览器窗口分辨率，按视口自适应的门户登录页需要调整 |
| User-Agent | `user_agent` | 空（跟随默认） | 自定义 UA |
| 附加请求头 | `extra_headers_json` | 空 | JSON 格式的额外请求头 |
| 附加浏览器参数 | `browser_args` | 空 | 每行一个，`#` 开头为注释；`--proxy-server` 等敏感参数会被过滤，纯净模式下不生效 |
| 绑定代理 | `bind_proxy` | 空 | 浏览器单独绑定的代理地址 |

## 网络监测与重试

对应字段前缀：`global.monitor`、`global.pause`、`global.retry_settings`。

原理性说明（探针如何选择、探测节奏的设计动机）见 [断网自动重连](../4-automation/4.1-monitor.md)，本节仅列出字段。

### 三探针字段

三种探针独立开关，**至少开启一种**才能触发自动登录，默认仅开启 HTTP 204。

| 探针 | 开关字段 | 默认值 | 目标字段 | 默认目标 | 判定方式 |
| --- | --- | --- | --- | --- | --- |
| TCP | `tcp_enabled` | 关 | `tcp_targets`（逗号分隔，缺省端口按 53） | `8.8.8.8:53`、`114.114.114.114:53`、`www.baidu.com:443` | 任一连通即在线 |
| HTTP 204 | `http_enabled` | **开** | `http_targets`（`generate_204` 端点） | `http://connect.rom.miui.com/generate_204`、`http://connectivitycheck.platform.hicloud.com/generate_204`、`http://wifi.vivo.com.cn/generate_204` | `204` 为在线、`200` 为被劫持，必须明文 `http` |
| URL 标题 | `url_enabled` | 关 | `url_targets` + `url_expected_responses` 映射 | Apple / Firefox / Microsoft 三个检测页及对应关键字 | 标题包含关键字即在线 |

URL 探针默认目标（每行 `地址|关键字`）：

```text
http://captive.apple.com/hotspot-detect.html|Success
http://detectportal.firefox.com/success.txt|success
http://www.msftconnecttest.com/connecttest.txt|Microsoft Connect Test
```

> [!WARNING]
> 常见配置错误：将 204 目标填成普通网页（恒返回 200，会被误判为「被劫持」而反复登录）；URL 关键字与真实标题不一致（恒判定为劫持或恒判定为在线）。

### 登录前检测

| 开关 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 网卡连接检查 | `local_check_enabled` | 开 | 物理网卡全部断开时直接判定离线，跳过外网探测与登录 |
| 认证地址可达检查 | 认证地址预检 | — | 登录前确认 `auth_url` 可达，不可达则跳过本次；劫持型网络自动跳过 |
| 监测不走代理 | `disable_proxy` | 开（直连） | 开启时探测直连、不跟随系统代理；关闭则跟随系统代理（重启生效）。仅影响网络检测，不影响更新与仓库下载 |

### 超时与间隔

| 参数 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 检测间隔 | `check_interval` | 300 秒 | 网络平稳时两次检测的**上限**，实际为自适应值 |
| TCP 超时 | `tcp_timeout` | 2 秒 | 单次 TCP 探测的等待上限 |
| HTTP 超时 | `http_timeout` | 10 秒 | 单次 204 探测的等待上限 |
| URL 超时 | `url_timeout` | 10 秒 | 单次标题探测的等待上限 |
| 认证地址超时 | `auth_url_timeout` | 5 秒 | 登录前认证地址预检的超时 |
| 登录后延迟 | `post_login_delay` | 5 秒（范围 0–60） | 登录后等待门户生效再复查网络 |
| 方案切换间隔 | `profile_check_interval` | 180 秒 | 自动切换配置方案的探测周期 |

### 重试策略

对应字段前缀：`global.retry_settings`。

| 参数 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 最大重试次数 | `max_retries` | 3 | 单次会话内登录失败后的最大重试次数 |
| 重试间隔 | `retry_interval` | 5 秒 | 首次重试间隔，之后指数退避 `5 → 10 → 20` 秒；设置过短可能触发门户限流 |
| 登录冷却 | 固定常量 | 连续失败 3 次后冷却 300 秒 | 冷却期内不再自动登录，以防账号被临时封禁；结束后自动恢复，无需重启 |

自适应探测节奏说明：`check_interval` 是上限而非固定值——在线（`Online`）时从 30 秒起指数放大（30 → 60 → 120…），最大不超过 `check_interval`；异常（`CaptivePortal` / `Offline`）时固定为 30 秒。即掉线后最快约 30 秒内开始重连；持续在线时逐步拉长间隔以降低开销。需立即验证时可点击控制台「立即检测」（后台执行，30 秒超时）。

### 暂停时段

对应字段前缀：`global.pause`。支持跨天设置（如 `22:00 → 06:00` 表示每晚 22 点至次日 6 点暂停）。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `false` | 是否启用暂停时段 |
| `start_hour` / `start_minute` | 0 / 0 | 开始时间 |
| `end_hour` / `end_minute` | 0 / 0 | 结束时间 |

暂停时段内监测与自动登录完全静默，但手动登录与定时任务不受影响。

## 应用、Worker 与日志

对应字段前缀：`global.app`、`global.worker`、`global.logging`。

### 应用设置

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 自动打开控制台 | `auto_start_browser` | `true` | 启动后是否自动使用浏览器打开控制台 |
| 运行模式 | `runtime_mode` | `full` | `full` 完整 / `lightweight` 轻量（仅引擎与托盘，控制台按需唤起；macOS 自动回落 `full`） |
| 启动后执行 | `startup_action` | `monitor` | `monitor` 进入网络监测 / `login_once` 先登录一次 / `none` 不动作；可用 `--startup-action` 覆盖 |
| 控制台端口 | `port` | `50721` | 监听端口，被占用时自动递增、最多重试 5 次；可用 `--port` / `CAMPUS_AUTH_PORT` 覆盖 |
| 开机自启 | `autostart_enabled` | `false` | 是否注册系统自启（Windows 注册表启动项 / macOS LaunchAgent / Linux XDG 自启），也可用 `--autostart enable/disable` |
| 任务通知 | `task_notification` | `true` | 任务完成后是否发送系统通知 |
| 开发者模式 | `developer_mode` | `false` | 是否启用开发者辅助功能 |
| 显示托盘 | `show_tray` | `true` | 是否显示托盘图标，关闭后仅保留 Web 控制台 |
| 定时自重启 | `auto_restart_hours` | `24` | 每运行指定小时数优雅自重启一次，回收浏览器 / Worker 内存；`0` 为关闭；运行时修改无需重启（每分钟读取一次） |

### Worker 设置

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 保持浏览器进程 | `keep_alive` | `false` | 登录后让浏览器常驻以加快下次登录；开关位于 设置 → 浏览器 的会话保持区 |
| 空闲回收超时 | `idle_timeout_seconds` | `300` | `keep_alive=false` 时，Worker 空闲达到该时长后自动回收 |

> [!TIP]
> 默认的 `keep_alive=false` 为「即用即还」模式，适合内存敏感场景；若改为常驻，建议配合「定时自重启」控制内存增长。

### 日志设置

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 日志级别 | `level` | `INFO` | `ERROR / WARN / INFO / DEBUG / TRACE`，设置页热更新、无需重启 |
| 写入文件 | `file_enabled` | `true` | 是否写入 `logs/` 目录 |
| 保留天数 | `retention_days` | `7` | 日志按天归档为 `app.log.YYYY-MM-DD`，超期自动清理 |

补充：实时日志走 `/ws/logs`，网络状态走 `/ws/status`；日志按天切分、仅按保留天数清理；级别对整个程序统一生效，不支持 `OFF`（写入会回退为 `INFO`），需要完全静默请关闭「写入文件」。

## 自动更新

对应字段前缀：`global.updater`。

| 配置项 | 字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 启动检查 | `check_on_startup` | `true` | 启动时是否检查；仅当检查间隔为「每次启动」时独立生效 |
| 自动检查总开关 | `auto_check_enabled` | `true` | 关闭后后台与启动检查均静默，仅保留手动「立即检查」 |
| 更新通道 | `channel` | `stable` | `stable` 正式 / `prerelease` 测试 / `all` 全通道取最高版本 |
| 发布源 | `release_source_url` | GitHub Releases API | 发布清单地址 |
| 检查间隔 | `check_interval_hours` | `24` | `0` 为仅启动检查；界面显示为「每次启动 / 每天 / 每周」（`0 / 24 / 168`） |
| 使用代理 | `use_proxy` | `false` | 是否使用显式代理下载更新 |
| 代理地址 | `proxy_url` | 空 | 如 `http://127.0.0.1:7890`，支持非本机代理 |
| 兼容字段 | `proxy_port` | `7890` | 旧版「本地代理端口」，仅用于兼容读取，新配置统一写入 `proxy_url` |

代理解析顺序：`proxy_url` 优先 → 否则由 `proxy_port` 拼出 `http://127.0.0.1:{port}` → 两者均为空则跟随系统代理。该代理仅作用于程序更新与任务仓库下载，与网络检测的「监测不走代理」相互独立。

更新功能的使用说明见 [自动更新](../5-maintenance/5.1-update.md)。每次检查结果都会刷新 `update/last_check.json`；产物下载到 `update/staging/`，下载前执行 `.sha256` 校验，自替换由 `campus-auth-helper` 完成。

    },
    "monitor": {
      "check_interval": 300,

      "http_enabled": true,
      "http_targets": ["http://connect.rom.miui.com/generate_204"],
      "url_enabled": false,
      "url_targets": ["http://captive.apple.com/hotspot-detect.html"],

        "http://captive.apple.com/hotspot-detect.html": "Success"
