# 浏览器与验证码

本页面汇总浏览器引擎、窗口显示、会话保持与验证码 OCR 的常见问题。参数细节见 [settings.json 配置参考](../6-reference/6.1-settings.md)。

## 后台运行（是否显示窗口）

### 如何让登录过程可见，便于排查？

进入 **设置 → 浏览器**，关闭 **后台运行（无头模式）** 并保存，再次执行任务即可看到完整操作过程；调试完成后重新开启，使其静默执行。

界面中没有名为 `headless` 的输入框，它对应的就是「后台运行」这一个开关。

## 浏览器选择与启动参数

### 可选择哪些浏览器？

控制台提供卡片式选择，默认 `msedge`，另可选 `chromium` / `chrome` / `firefox` / `webkit`，也可通过自定义路径指向本机已安装的浏览器。本机已有 Edge / Chrome 时会直接复用，无需额外下载。

### 如何附加浏览器启动参数？

在高级设置（需先关闭「纯净模式」）的 `browser_args` 中按行填写，每行一个、`#` 开头为注释。`--proxy-server` 等敏感参数会被过滤，纯净模式下不生效。

### 视口 / 语言 / 时区需要修改吗？

大多数校园网无需修改，默认值为 `1280×720`、`zh-CN`、`Asia/Shanghai`。仅当门户登录页按视口自适应布局时才需要调整视口（位于高级设置，纯净模式下隐藏）。

## 会话保持与常驻

### 如何让浏览器记住登录状态或保持进程常驻？

在 设置 → 浏览器 → 会话保持 中配置：

- **记住登录状态**（`persistent_context`）：将 Cookie 等持久化到 `config/browser-data/{channel}/`，按浏览器隔离；Firefox 不支持该能力。
- **登录后保持浏览器进程**（`keep_alive`）：加快下次登录速度，关闭后空闲 300 秒自动回收。
- 页面右下角「立即关闭浏览器」用于调试或更换配置，会中断正在进行的登录。

## 验证码 OCR

### 是否必须安装 OCR 依赖？

仅当任务中包含 `ocr` 步骤时才需要。`ddddocr` 含推理库、体积约百 MB 级，可在 设置 → 任务 查看状态并一键安装 / 卸载；不安装也不影响其他任务。安装完成后可使用同页「验证码识别」上传图片自测。

### 验证码识别失败或反复重试？

- 区分两个选择器：`ocr` 的 `selector` 指向验证码**图片**，`target_selector` 才是待回填的**输入框**，二者不要混淆。
- 图片过小或干扰线较重时，可在 `ocr` 步骤前增加 `wait_for_selector`，待图片加载完成后再识别。
- 需要点击刷新验证码的门户，由上层登录重试机制整体重跑，无需手动干预；`ocr` 步骤本身仅识别一次，不做步骤内重试。
- 若开启了「低资源模式」（不加载图片），OCR 将无图可识别，请关闭该模式。
