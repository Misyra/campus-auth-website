# 定时、开机与更新

## 定时任务

**如何配置定时任务？**

在定时任务页面（`/scheduled`）通过 cron 表达式配置（5 段：`分 时 日 月 周`），如 `0 8 * * *` 表示每日 8 时执行，先通过“执行指定任务”验证稳定性后再配置为定时任务。详见 [定时任务](../4-automation/4.3-scheduled.md)。

**开机自启被拦截如何处理？**

通过 设置 → 系统 → 启动与运行中的 **开机自启动** 选项，或执行 `campus-auth --autostart enable`（Windows 写入注册表 Run 键，安全软件可能拦截，需将 `campus-auth.exe` 加入白名单后重试）。

**长期运行内存占用增长如何处理？**

通过 设置 → 系统 → 维护操作中的 **定时自重启**（`auto_restart_hours` 默认 24 小时）与 设置 → 浏览器中的 **保持浏览器进程** 配合使用；`keep_alive=false` 时默认为即用即还模式（`idle_timeout 300s` 回收）。详见 [应用与日志](../6-reference/6.3-system.md)。

## 更新

**如何查看更新？**

在 **关于** 页面点击“检查更新”，检查结果回写至 `update/last_check.json`，在 设置 → 系统 中可查看“上次检查时间”与错误提示；更新通道分为正式版 / 测试版 / 全通道最新版。详见 [自动更新](../5-system/5.2-update.md)。

## 任务配置

**`eval` 保存时为何弹出安全警告？**

`eval` / `custom_js` 可执行任意 JS 代码，系统将弹出确认对话框，确认安全性后方可保存。

**运营商下拉选项如何配置？**

原生 `<select>` 使用 `select` 步骤，自定义下拉使用 `click_select`（`selector` 点击展开 + `option_selector` 选项范围 + `value={{ISP}}`），无该下拉时设置 `required: false`。

**多校区如何配置？**

程序首次启动时自动生成 `default` 配置方案，多网络环境需另行新建配置方案，各自填写 `gateway_ip` / `wifi_ssid` 并启用 `auto_switch`，分别绑定 `active_task`，而非为每种环境维护独立的 JSON 副本；编辑器内“检测当前网络”支持一键填入。详见 [自动匹配](../2-profiles/2.2-match.md)。
